4  The Preprocessing Pipeline

4.1 Learning Objectives

By the end of this lesson, you will:

  1. Understand why preprocessing is critical for FC analysis
  2. Know what confound regression does and which confounds we use
  3. Understand bandpass filtering and its purpose
  4. Learn about motion scrubbing and volume censoring
  5. See the complete preprocessing pipeline in action

4.2 3.1 Why Preprocessing Matters

4.2.1 The Problem: Noise in fMRI

Raw BOLD signal contains many non-neural signals:

Noise Source Frequency Effect on FC
Head motion Variable Huge: Can create false correlations
Respiration ~0.2-0.3 Hz Moderate: Synchronized across brain
Cardiac ~1 Hz Low-moderate: Pulsatile artifacts
Scanner drift <0.01 Hz High: Slow trends inflate correlations
Thermal noise Broadband Low: Random, averages out

4.2.2 The Goal

Remove non-neural signals while preserving the neural signal (0.01-0.1 Hz).

Raw BOLD = Neural Signal + Motion + Physiology + Drift + Noise
                |
         Preprocessing
                |
Clean BOLD = Neural Signal (hopefully!)

4.3 3.2 The Preprocessing Pipeline Steps

Our pipeline applies these steps in order:

1. Load Data
       |
2. Confound Regression (remove noise regressors)
       |
3. Volume Censoring (remove high-motion timepoints)
       |
4. Bandpass Filtering (0.01-0.1 Hz)
       |
5. Compute Connectivity

4.3.1 Why This Order?

  • Confound regression before censoring: Regression works better with continuous data
  • Censoring before filtering: Prevents artifacts from spreading during filtering
  • Filtering last: Clean temporal profile for correlation

4.4 3.3 Confound Regression

4.4.1 What is Confound Regression?

We model each voxel’s timeseries as:

\[Y = X\beta + \epsilon\]

Where:

  • \(Y\) = observed BOLD signal
  • \(X\) = matrix of confound regressors
  • \(\beta\) = regression coefficients
  • \(\epsilon\) = residuals (what we keep!)

def regress_confounds(data, confounds):
    """
    Regress out confound signals from data.

    This is from run_segregation_python.py

    Parameters
    ----------
    data : np.ndarray
        Shape: (time, features)
    confounds : np.ndarray or pd.DataFrame
        Confound matrix (time, n_confounds)

    Returns
    -------
    residuals : np.ndarray
        Data with confounds removed
    """
    # Get confound matrix
    if hasattr(confounds, 'values'):
        X = confounds.values
    else:
        X = confounds

    # Add intercept (constant term)
    X = np.column_stack([X, np.ones(X.shape[0])])

    # Solve: data = X @ beta, find beta that minimizes error
    # Then: residuals = data - X @ beta
    beta = np.linalg.lstsq(X, data, rcond=None)[0]
    residuals = data - X @ beta

    return residuals

4.5 3.4 Motion Scrubbing (Volume Censoring)

4.5.1 Why Censoring?

Confound regression can’t fully remove severe motion artifacts. Solution: remove the bad volumes entirely.

4.5.2 Framewise Displacement (FD)

FD measures head movement between consecutive volumes:

\[FD = |\Delta x| + |\Delta y| + |\Delta z| + |\Delta \alpha|r + |\Delta \beta|r + |\Delta \gamma|r\]

Where:

  • \(\Delta x, y, z\) = translation changes (mm)
  • \(\Delta \alpha, \beta, \gamma\) = rotation changes (radians)
  • \(r\) = 50mm (assumed head radius, converts rotation to arc length)

4.5.3 Our Criteria

Parameter Value Meaning
FD Threshold 0.3 mm Volumes with FD > 0.3 are flagged
Scrub Before 1 volume Remove 1 volume before motion
Scrub After 2 volumes Remove 2 volumes after motion
Max Censored 20% Exclude subject if >20% volumes censored 
def create_censoring_mask(fd, threshold, scrub_before=1, scrub_after=2):
    """
    Create a mask for censoring high-motion volumes.

    From segregation_utils.py

    Parameters
    ----------
    fd : np.ndarray
        Framewise displacement for each volume
    threshold : float
        FD threshold (e.g., 0.3 mm)
    scrub_before : int
        Volumes to censor before high-motion
    scrub_after : int
        Volumes to censor after high-motion

    Returns
    -------
    mask : np.ndarray
        Boolean array: True = keep, False = censor
    """
    n_vols = len(fd)
    mask = np.ones(n_vols, dtype=bool)  # Start with all True (keep all)

    # Find volumes exceeding threshold
    bad_vols = np.where(fd > threshold)[0]

    for vol in bad_vols:
        # Censor the bad volume itself
        mask[vol] = False

        # Censor volumes before
        for i in range(1, scrub_before + 1):
            if vol - i >= 0:
                mask[vol - i] = False

        # Censor volumes after
        for i in range(1, scrub_after + 1):
            if vol + i < n_vols:
                mask[vol + i] = False

    return mask

4.6 3.5 Bandpass Filtering

4.6.1 Why Filter?

Resting-state neural signals are concentrated in a specific frequency band:

Component Frequency Action
Scanner drift < 0.01 Hz Remove (high-pass)
Neural signal 0.01 - 0.1 Hz Keep
Respiration 0.2 - 0.3 Hz Remove (low-pass)
Cardiac ~1 Hz Remove (low-pass)

4.6.2 Our Settings

  • High-pass cutoff: 0.01 Hz (removes drift)
  • Low-pass cutoff: 0.1 Hz (removes physiology)
  • Filter type: Butterworth (smooth frequency response)
def bandpass_filter(data, tr, low_freq, high_freq):
    """
    Apply bandpass filter to data.

    From run_segregation_python.py

    Parameters
    ----------
    data : np.ndarray
        Shape: (time, features)
    tr : float
        Repetition time in seconds
    low_freq : float
        Low frequency cutoff (Hz)
    high_freq : float
        High frequency cutoff (Hz)

    Returns
    -------
    filtered : np.ndarray
        Bandpass filtered data
    """
    # Sampling frequency
    fs = 1 / tr

    # Nyquist frequency (max observable frequency)
    nyq = fs / 2

    # Normalized frequencies
    low = low_freq / nyq
    high = high_freq / nyq

    # Design Butterworth bandpass filter
    b, a = signal.butter(2, [low, high], btype='band')

    # Apply filter (forward-backward for zero phase shift)
    filtered = signal.filtfilt(b, a, data, axis=0)

    return filtered

# Compute power spectra
def compute_power_spectrum(data, tr):
    """Compute power spectrum of a signal."""
    n = len(data)
    fs = 1 / tr
    freqs = np.fft.rfftfreq(n, tr)
    power = np.abs(np.fft.rfft(data)) ** 2
    return freqs, power / power.max()  # Normalize

4.7 3.6 The Complete Pipeline

Now let’s see how all steps work together:

def preprocess_subject(data, confounds, fd,
                       tr=1.124,
                       fd_threshold=0.3,
                       scrub_before=1,
                       scrub_after=2,
                       bandpass_low=0.01,
                       bandpass_high=0.1,
                       max_censored_prop=0.20):
    """
    Complete preprocessing pipeline for a single subject.

    This mirrors what run_segregation_python.py does.

    Returns
    -------
    data_clean : np.ndarray or None
        Preprocessed data, or None if excluded
    info : dict
        Processing information
    """
    info = {}

    # Step 1: Check motion criteria
    censor_mask = create_censoring_mask(fd, fd_threshold, scrub_before, scrub_after)
    prop_censored = 1 - censor_mask.mean()

    info['n_volumes_original'] = len(fd)
    info['n_censored'] = np.sum(~censor_mask)
    info['prop_censored'] = prop_censored
    info['mean_fd'] = np.mean(fd)

    # Check if too much censored
    if prop_censored > max_censored_prop:
        info['excluded'] = True
        info['exclusion_reason'] = f'Too much motion ({prop_censored*100:.1f}% censored)'
        return None, info

    # Check if mean FD too high
    if np.mean(fd) > fd_threshold:
        info['excluded'] = True
        info['exclusion_reason'] = f'Mean FD too high ({np.mean(fd):.3f} mm)'
        return None, info

    # Step 2: Confound regression
    print("  Step 1: Regressing confounds...")
    data_regressed = regress_confounds(data, confounds)

    # Step 3: Apply censoring mask
    print("  Step 2: Applying censoring mask...")
    data_censored = data_regressed[censor_mask, :]
    info['n_volumes_used'] = len(data_censored)

    # Step 4: Bandpass filter
    print("  Step 3: Bandpass filtering...")
    data_filtered = bandpass_filter(data_censored, tr, bandpass_low, bandpass_high)

    info['excluded'] = False
    print(f"  Done! {info['n_volumes_used']}/{info['n_volumes_original']} volumes retained")

    return data_filtered, info

4.8 3.7 Key Takeaways

4.8.1 Summary

  1. Preprocessing removes non-neural signals while preserving the neural signal

  2. Confound regression uses fMRIPrep-derived nuisance regressors:

    • CompCor (physiological noise)
    • Motion parameters + derivatives
    • Spike regressors for outliers

  3. Volume censoring removes timepoints with high motion:

    • FD > 0.3 mm threshold
    • Includes 1 volume before, 2 after
    • Subjects excluded if >20% censored

  4. Bandpass filtering (0.01-0.1 Hz) isolates neural frequencies

  5. Order matters: Regression -> Censoring -> Filtering

4.8.2 Connection to the Pipeline

In run_segregation_python.py:

  • load_confounds() loads and selects confound regressors
  • get_framewise_displacement() extracts FD
  • regress_confounds() performs regression
  • create_censoring_mask() handles motion scrubbing
  • bandpass_filter() applies frequency filtering

## 3.1 Why Preprocessing Matters

### The Problem: Noise in fMRI

Raw BOLD signal contains many **non-neural signals**:

| Noise Source | Frequency | Effect on FC |
|--------------|-----------|-------------|
| Head motion | Variable | **Huge**: Can create false correlations |
| Respiration | ~0.2-0.3 Hz | Moderate: Synchronized across brain |
| Cardiac | ~1 Hz | Low-moderate: Pulsatile artifacts |
| Scanner drift | <0.01 Hz | High: Slow trends inflate correlations |
| Thermal noise | Broadband | Low: Random, averages out |

### The Goal

Remove non-neural signals while **preserving the neural signal** (0.01-0.1 Hz).

```
Raw BOLD = Neural Signal + Motion + Physiology + Drift + Noise
                |
         Preprocessing
                |
Clean BOLD = Neural Signal (hopefully!)
```

## 3.2 The Preprocessing Pipeline Steps

Our pipeline applies these steps **in order**:

```
1. Load Data
       |
2. Confound Regression (remove noise regressors)
       |
3. Volume Censoring (remove high-motion timepoints)
       |
4. Bandpass Filtering (0.01-0.1 Hz)
       |
5. Compute Connectivity
```

### Why This Order?

- **Confound regression before censoring**: Regression works better with continuous data
- **Censoring before filtering**: Prevents artifacts from spreading during filtering
- **Filtering last**: Clean temporal profile for correlation

## 3.3 Confound Regression

### What is Confound Regression?

We model each voxel's timeseries as:

$$Y = X\beta + \epsilon$$

Where:

- $Y$ = observed BOLD signal
- $X$ = matrix of confound regressors
- $\beta$ = regression coefficients
- $\epsilon$ = residuals (what we keep!)

### Confounds Used in This Pipeline

```{python}
#| label: confound-regression-demo
#| fig-cap: "Effect of confound regression"

def regress_confounds(data, confounds):
    """
    Regress out confound signals from data.

    This is from run_segregation_python.py

    Parameters
    ----------
    data : np.ndarray
        Shape: (time, features)
    confounds : np.ndarray or pd.DataFrame
        Confound matrix (time, n_confounds)

    Returns
    -------
    residuals : np.ndarray
        Data with confounds removed
    """
    # Get confound matrix
    if hasattr(confounds, 'values'):
        X = confounds.values
    else:
        X = confounds

    # Add intercept (constant term)
    X = np.column_stack([X, np.ones(X.shape[0])])

    # Solve: data = X @ beta, find beta that minimizes error
    # Then: residuals = data - X @ beta
    beta = np.linalg.lstsq(X, data, rcond=None)[0]
    residuals = data - X @ beta

    return residuals
```

## 3.4 Motion Scrubbing (Volume Censoring)

### Why Censoring?

Confound regression can't fully remove severe motion artifacts. Solution: **remove the bad volumes entirely**.

### Framewise Displacement (FD)

FD measures head movement between consecutive volumes:

$$FD = |\Delta x| + |\Delta y| + |\Delta z| + |\Delta \alpha|r + |\Delta \beta|r + |\Delta \gamma|r$$

Where:

- $\Delta x, y, z$ = translation changes (mm)
- $\Delta \alpha, \beta, \gamma$ = rotation changes (radians)
- $r$ = 50mm (assumed head radius, converts rotation to arc length)

### Our Criteria

| Parameter | Value | Meaning |
|-----------|-------|--------|
| FD Threshold | 0.3 mm | Volumes with FD > 0.3 are flagged |
| Scrub Before | 1 volume | Remove 1 volume before motion |
| Scrub After | 2 volumes | Remove 2 volumes after motion |
| Max Censored | 20% | Exclude subject if >20% volumes censored |

```{python}
#| label: censoring-demo
#| fig-cap: "Motion trace with censoring"

def create_censoring_mask(fd, threshold, scrub_before=1, scrub_after=2):
    """
    Create a mask for censoring high-motion volumes.

    From segregation_utils.py

    Parameters
    ----------
    fd : np.ndarray
        Framewise displacement for each volume
    threshold : float
        FD threshold (e.g., 0.3 mm)
    scrub_before : int
        Volumes to censor before high-motion
    scrub_after : int
        Volumes to censor after high-motion

    Returns
    -------
    mask : np.ndarray
        Boolean array: True = keep, False = censor
    """
    n_vols = len(fd)
    mask = np.ones(n_vols, dtype=bool)  # Start with all True (keep all)

    # Find volumes exceeding threshold
    bad_vols = np.where(fd > threshold)[0]

    for vol in bad_vols:
        # Censor the bad volume itself
        mask[vol] = False

        # Censor volumes before
        for i in range(1, scrub_before + 1):
            if vol - i >= 0:
                mask[vol - i] = False

        # Censor volumes after
        for i in range(1, scrub_after + 1):
            if vol + i < n_vols:
                mask[vol + i] = False

    return mask

# Simulate FD data
np.random.seed(42)
n_vols = 300

# Baseline FD (low motion)
fd_simulated = np.abs(np.random.randn(n_vols) * 0.1)

# Add some high-motion events
high_motion_times = [50, 120, 121, 200]
fd_simulated[high_motion_times] = [0.8, 1.2, 0.9, 0.6]

# Create mask
FD_THRESHOLD = 0.3
mask = create_censoring_mask(fd_simulated, FD_THRESHOLD, scrub_before=1, scrub_after=2)

# Visualize
fig, axes = plt.subplots(2, 1, figsize=(14, 6), sharex=True)

# FD plot
axes[0].plot(fd_simulated, 'b-', linewidth=1)
axes[0].axhline(FD_THRESHOLD, color='red', linestyle='--', label=f'Threshold ({FD_THRESHOLD} mm)')
axes[0].fill_between(range(n_vols), 0, fd_simulated, where=~mask,
                     color='red', alpha=0.3, label='Censored')
axes[0].set_ylabel('Framewise Displacement (mm)')
axes[0].set_title('Motion Trace with Censoring', fontsize=12)
axes[0].legend()
axes[0].set_ylim(0, 1.5)

# Mask visualization

               extent=[0, n_vols, 0, 1])
axes[1].set_xlabel('Volume')

axes[1].set_title(f'Censoring Mask: {mask.sum()}/{n_vols} volumes kept ({100*mask.mean():.1f}%)', fontsize=12)
axes[1].set_yticks([])

plt.tight_layout()
plt.show()

print(f"Volumes above threshold: {np.sum(fd_simulated > FD_THRESHOLD)}")
print(f"Total volumes censored: {np.sum(~mask)} (including padding)")
print(f"Volumes retained: {np.sum(mask)} ({100*mask.mean():.1f}%)")
```

## 3.5 Bandpass Filtering

### Why Filter?

Resting-state neural signals are concentrated in a specific frequency band:

| Component | Frequency | Action |
|-----------|-----------|--------|
| Scanner drift | < 0.01 Hz | Remove (high-pass) |
| **Neural signal** | **0.01 - 0.1 Hz** | **Keep** |
| Respiration | 0.2 - 0.3 Hz | Remove (low-pass) |
| Cardiac | ~1 Hz | Remove (low-pass) |

### Our Settings

- **High-pass cutoff**: 0.01 Hz (removes drift)
- **Low-pass cutoff**: 0.1 Hz (removes physiology)
- **Filter type**: Butterworth (smooth frequency response)

```{python}
#| label: bandpass-demo
#| fig-cap: "Effect of bandpass filtering"

def bandpass_filter(data, tr, low_freq, high_freq):
    """
    Apply bandpass filter to data.

    From run_segregation_python.py

    Parameters
    ----------
    data : np.ndarray
        Shape: (time, features)
    tr : float
        Repetition time in seconds
    low_freq : float
        Low frequency cutoff (Hz)
    high_freq : float
        High frequency cutoff (Hz)

    Returns
    -------
    filtered : np.ndarray
        Bandpass filtered data
    """
    # Sampling frequency
    fs = 1 / tr

    # Nyquist frequency (max observable frequency)
    nyq = fs / 2

    # Normalized frequencies
    low = low_freq / nyq
    high = high_freq / nyq

    # Design Butterworth bandpass filter
    b, a = signal.butter(2, [low, high], btype='band')

    # Apply filter (forward-backward for zero phase shift)
    filtered = signal.filtfilt(b, a, data, axis=0)

    return filtered

# Demonstrate filtering
TR = 1.124
LOW_FREQ = 0.01
HIGH_FREQ = 0.1

# Apply to our simulated data (after regression)
filtered = bandpass_filter(residuals, TR, LOW_FREQ, HIGH_FREQ)

# Compute power spectra
def compute_power_spectrum(data, tr):
    """Compute power spectrum of a signal."""
    n = len(data)
    fs = 1 / tr
    freqs = np.fft.rfftfreq(n, tr)
    power = np.abs(np.fft.rfft(data)) ** 2
    return freqs, power / power.max()  # Normalize

freqs_raw, power_raw = compute_power_spectrum(raw_bold, TR)
freqs_filt, power_filt = compute_power_spectrum(filtered[:, 0], TR)
```

## 3.6 The Complete Pipeline

Now let's see how all steps work together:

```{python}
#| label: complete-pipeline
#| echo: true

def preprocess_subject(data, confounds, fd,
                       tr=1.124,
                       fd_threshold=0.3,
                       scrub_before=1,
                       scrub_after=2,
                       bandpass_low=0.01,
                       bandpass_high=0.1,
                       max_censored_prop=0.20):
    """
    Complete preprocessing pipeline for a single subject.

    This mirrors what run_segregation_python.py does.

    Returns
    -------
    data_clean : np.ndarray or None
        Preprocessed data, or None if excluded
    info : dict
        Processing information
    """
    info = {}

    # Step 1: Check motion criteria
    censor_mask = create_censoring_mask(fd, fd_threshold, scrub_before, scrub_after)
    prop_censored = 1 - censor_mask.mean()

    info['n_volumes_original'] = len(fd)
    info['n_censored'] = np.sum(~censor_mask)
    info['prop_censored'] = prop_censored
    info['mean_fd'] = np.mean(fd)

    # Check if too much censored
    if prop_censored > max_censored_prop:
        info['excluded'] = True
        info['exclusion_reason'] = f'Too much motion ({prop_censored*100:.1f}% censored)'
        return None, info

    # Check if mean FD too high
    if np.mean(fd) > fd_threshold:
        info['excluded'] = True
        info['exclusion_reason'] = f'Mean FD too high ({np.mean(fd):.3f} mm)'
        return None, info

    # Step 2: Confound regression
    print("  Step 1: Regressing confounds...")
    data_regressed = regress_confounds(data, confounds)

    # Step 3: Apply censoring mask
    print("  Step 2: Applying censoring mask...")
    data_censored = data_regressed[censor_mask, :]
    info['n_volumes_used'] = len(data_censored)

    # Step 4: Bandpass filter
    print("  Step 3: Bandpass filtering...")
    data_filtered = bandpass_filter(data_censored, tr, bandpass_low, bandpass_high)

    info['excluded'] = False
    print(f"  Done! {info['n_volumes_used']}/{info['n_volumes_original']} volumes retained")

    return data_filtered, info

# Demonstrate with simulated multi-voxel data
np.random.seed(42)
n_timepoints = 300
n_voxels = 100

# Simulate data (time x voxels)
simulated_data = np.random.randn(n_timepoints, n_voxels)

# Add some structure (correlated noise)

    simulated_data[:, i] += common_noise * 0.5

    simulated_data,
    simulated_confounds,
    simulated_fd
)

print(f"\nProcessing summary:")
for key, value in proc_info.items():
    print(f"  {key}: {value}")
```

## 3.7 Key Takeaways

### Summary

1. **Preprocessing removes non-neural signals** while preserving the neural signal

2. **Confound regression** uses fMRIPrep-derived nuisance regressors:
   - CompCor (physiological noise)
   - Motion parameters + derivatives
   - Spike regressors for outliers

3. **Volume censoring** removes timepoints with high motion:
   - FD > 0.3 mm threshold
   - Includes 1 volume before, 2 after
   - Subjects excluded if >20% censored

4. **Bandpass filtering** (0.01-0.1 Hz) isolates neural frequencies

5. **Order matters**: Regression -> Censoring -> Filtering

### Connection to the Pipeline

In `run_segregation_python.py`:

- `load_confounds()` loads and selects confound regressors
- `get_framewise_displacement()` extracts FD
- `regress_confounds()` performs regression
- `create_censoring_mask()` handles motion scrubbing
- `bandpass_filter()` applies frequency filtering
