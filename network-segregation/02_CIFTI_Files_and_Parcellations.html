3  CIFTI Files and Brain Parcellations

3.1 Learning Objectives

By the end of this lesson, you will:

  1. Understand the CIFTI file format and why it exists
  2. Know what “grayordinates” are
  3. Understand the Cole-Anticevic 12-network parcellation
  4. Be able to load and explore CIFTI data in Python

3.2 2.1 The Problem with Traditional fMRI Formats

3.2.1 NIfTI: The Traditional Approach

Traditional fMRI uses NIfTI format (.nii files):

  • 3D grid of voxels (volumetric pixels)
  • Same grid for cortex and subcortex
  • Problem: Cortex is a 2D sheet folded into 3D
NIfTI Approach:
+------------------+
| [ ] [ ] [ ] [ ]  |  <- Voxel grid treats cortex
| [ ] [X] [X] [ ]  |     as 3D volume
| [ ] [X] [X] [X]  |
| [ ] [ ] [X] [X]  |  <- Nearby voxels in 3D may be
| [ ] [ ] [ ] [X]  |     far apart on cortical surface
+------------------+

3.2.2 Problems with Volumetric Representation

  1. Spatial inaccuracy: Neighboring voxels may be far apart on the cortical surface
  2. Smoothing artifacts: Gaussian smoothing bleeds across sulci
  3. Registration challenges: Aligning folded cortex across subjects is hard
  4. Wasted space: Many voxels are CSF or white matter

3.3 2.2 CIFTI: The Surface + Volume Solution

3.3.1 What is CIFTI?

CIFTI (Connectivity Informatics Technology Initiative) combines:

  • Surface data for cortex (vertices on a mesh)
  • Volumetric data for subcortex (voxels)
CIFTI Approach:

Cortex (Surface):           Subcortex (Volume):
    /\                      +-------+
   /  \                     | X X X | <- Thalamus
  /    \  <- Vertices       | X X X | <- Basal ganglia
 /______\    on mesh        | X X X | <- Hippocampus
                            +-------+

3.3.2 Grayordinates: The Universal Index

CIFTI uses grayordinates - a combined index for all gray matter:

Index Range Structure Type
0 - 29,695 Left cortex Surface vertices
29,696 - 59,411 Right cortex Surface vertices
59,412 - 91,281 Subcortex Volume voxels

Total: 91,282 grayordinates (in standard HCP 91k mesh)

3.4 2.3 CIFTI File Types

3.4.1 Common CIFTI Extensions

Extension Full Name Content
.dtseries.nii Dense Timeseries fMRI timeseries at each grayordinate
.dscalar.nii Dense Scalar Single value per grayordinate (e.g., t-map)
.dlabel.nii Dense Label Integer label per grayordinate (parcellation)
.dconn.nii Dense Connectivity Full connectivity matrix
.pconn.nii Parcellated Connectivity Parcel-to-parcel connectivity

3.5 2.4 The Cole-Anticevic Parcellation

3.5.1 Why This Parcellation?

The Cole-Anticevic parcellation is ideal for our analysis because:

  1. 12 Functional Networks - Data-driven, validated network definitions
  2. Includes Subcortex - Networks extend to subcortical structures
  3. HCP Compatible - Works directly with HCP-style CIFTI files
  4. Widely Used - Enables comparison with other studies

3.6 2.5 Loading CIFTI Data in Python

3.6.1 Using NiBabel

The nibabel library can read CIFTI files. Here’s how the pipeline loads data:

def load_cifti_data(cifti_path):
    """
    Load CIFTI dtseries file and return data matrix and header.

    This is from run_segregation_python.py
    """
    print(f"Loading: {Path(cifti_path).name}")
    cifti = nib.load(str(cifti_path))
    data = cifti.get_fdata()  # Shape: (time, grayordinates)
    return data, cifti

def load_atlas(atlas_path):
    """
    Load Cole-Anticevic network parcellation.

    Returns network assignments (which network each grayordinate belongs to)
    and a dictionary mapping network IDs to names.
    """
    print(f"Loading atlas: {Path(atlas_path).name}")
    atlas = nib.load(str(atlas_path))
    data = atlas.get_fdata().squeeze()  # Shape: (grayordinates,)

    # Get label table from header
    header = atlas.header
    label_dict = {}

    if hasattr(header, 'get_axis'):
        label_axis = header.get_axis(0)
        if hasattr(label_axis, 'label'):
            for idx, (name, _) in label_axis.label[0].items():
                if idx > 0:  # Skip background
                    label_dict[idx] = name

    # Fall back to default labels if needed
    if not label_dict:
        label_dict = NETWORK_LABELS.copy()

    return data.astype(int), label_dict

3.7 2.6 From Grayordinates to Network Timeseries

3.7.1 The Averaging Process

To compute network connectivity, we need to:

  1. Load the timeseries at each grayordinate
  2. Average within each network to get network-level timeseries
  3. Correlate the network timeseries
def extract_network_timeseries(data, network_assignments):
    """
    Extract mean timeseries for each network.

    Parameters
    ----------
    data : np.ndarray
        Shape: (time, grayordinates)
    network_assignments : np.ndarray
        Network ID for each grayordinate

    Returns
    -------
    network_ts : np.ndarray
        Shape: (time, n_networks)
    network_ids : np.ndarray
        The network IDs
    """
    networks = np.unique(network_assignments)
    networks = networks[networks > 0]  # Exclude background

    n_time = data.shape[0]
    n_networks = len(networks)

    network_ts = np.zeros((n_time, n_networks))

    for i, net_id in enumerate(networks):
        # Find all grayordinates belonging to this network
        mask = network_assignments == net_id
        # Average their timeseries
        network_ts[:, i] = np.nanmean(data[:, mask], axis=1)

    return network_ts, networks

3.8 2.7 The Memory Challenge

3.8.1 Why We Don’t Compute Full Correlation Matrices

In theory, we could compute correlations between all pairs of grayordinates:

Full matrix: 91,282 x 91,282 = 8.3 BILLION values
Memory: 8.3e9 x 8 bytes = 66 GB!

This would crash most computers!

3.8.2 The Solution: Sampling

The pipeline uses a memory-efficient sampling approach:

  1. Sample ~500 grayordinates from each network
  2. Compute within/between correlations from samples
  3. This gives accurate estimates with tiny memory footprint
# Demonstrate the memory problem and solution
n_grayordinates_full = 91282

# Memory for full matrix
full_matrix_bytes = n_grayordinates_full ** 2 * 8  # 64-bit floats
full_matrix_gb = full_matrix_bytes / (1024**3)

# Memory for sampling approach
n_samples = 500
n_networks = 12
sampled_matrix_bytes = (n_samples * n_networks) ** 2 * 8
sampled_matrix_gb = sampled_matrix_bytes / (1024**3)

print("Memory Comparison")
print("=" * 50)
print(f"Full 91k x 91k matrix:")
print(f"  Elements: {n_grayordinates_full**2:,}")
print(f"  Memory: {full_matrix_gb:.1f} GB")
print(f"\nSampled approach (500 per network):")
print(f"  Elements: {(n_samples * n_networks)**2:,}")
print(f"  Memory: {sampled_matrix_gb:.3f} GB")
print(f"\nMemory reduction: {full_matrix_gb / sampled_matrix_gb:.0f}x smaller!")

# Visualize
fig, ax = plt.subplots(figsize=(8, 5))
bars = ax.bar(['Full Matrix\n(91,282^2)', 'Sampled\n(6,000^2)'],
              [full_matrix_gb, sampled_matrix_gb],
              color=['red', 'green'], alpha=0.7, edgecolor='black')
ax.set_ylabel('Memory (GB)', fontsize=12)
ax.set_title('Memory Requirements: Full vs Sampled Approach', fontsize=14)
ax.axhline(16, color='orange', linestyle='--', label='Typical laptop RAM (16 GB)')
ax.legend()

# Add labels
ax.text(0, full_matrix_gb + 2, f'{full_matrix_gb:.1f} GB', ha='center', fontsize=12)
ax.text(1, sampled_matrix_gb + 2, f'{sampled_matrix_gb:.3f} GB', ha='center', fontsize=12)

plt.tight_layout()
plt.show()

3.9 2.8 Key Takeaways

3.9.1 Summary

  1. CIFTI combines surface (cortex) and volume (subcortex) representations

  2. Grayordinates are the universal index for all gray matter (~91k in HCP)

  3. Cole-Anticevic parcellation assigns each grayordinate to one of 12 networks

  4. Networks are categorized as sensory-motor or association

  5. Memory-efficient sampling is essential for practical computation

3.9.2 Connection to the Pipeline

In run_segregation_python.py:

  • load_cifti_data() loads the .dtseries.nii file
  • load_atlas() loads the .dlabel.nii parcellation
  • compute_network_segregation_efficient() uses sampling to avoid memory issues

## 2.3 CIFTI File Types

### Common CIFTI Extensions

| Extension | Full Name | Content |
|-----------|-----------|--------|
| `.dtseries.nii` | Dense Timeseries | fMRI timeseries at each grayordinate |
| `.dscalar.nii` | Dense Scalar | Single value per grayordinate (e.g., t-map) |
| `.dlabel.nii` | Dense Label | Integer label per grayordinate (parcellation) |
| `.dconn.nii` | Dense Connectivity | Full connectivity matrix |
| `.pconn.nii` | Parcellated Connectivity | Parcel-to-parcel connectivity |

### In This Pipeline

We use:

- **`.dtseries.nii`** - The preprocessed fMRI data (time x grayordinates)

## 2.6 From Grayordinates to Network Timeseries

### The Averaging Process

To compute network connectivity, we need to:

1. Load the timeseries at each grayordinate
2. Average within each network to get network-level timeseries
3. Correlate the network timeseries

```{python}
#| label: network-timeseries
#| fig-cap: "Network-averaged timeseries extraction"

def extract_network_timeseries(data, network_assignments):
    """
    Extract mean timeseries for each network.

    Parameters
    ----------
    data : np.ndarray
        Shape: (time, grayordinates)
    network_assignments : np.ndarray
        Network ID for each grayordinate

    Returns
    -------
    network_ts : np.ndarray
        Shape: (time, n_networks)
    network_ids : np.ndarray
        The network IDs
    """
    networks = np.unique(network_assignments)
    networks = networks[networks > 0]  # Exclude background

    n_time = data.shape[0]
    n_networks = len(networks)

    network_ts = np.zeros((n_time, n_networks))

    for i, net_id in enumerate(networks):
        # Find all grayordinates belonging to this network
        mask = network_assignments == net_id
        # Average their timeseries
        network_ts[:, i] = np.nanmean(data[:, mask], axis=1)

    return network_ts, networks

# Demonstrate with simulated data
np.random.seed(42)
n_timepoints = 300
n_grayordinates = 1000  # Simplified

# Create fake network assignments (3 networks)
fake_assignments = np.random.randint(1, 4, size=n_grayordinates)

# Create fake timeseries with network structure

for net_id in [1, 2, 3]:
    mask = fake_assignments == net_id
    # All grayordinates in same network share a common signal
```

## 2.7 The Memory Challenge

### Why We Don't Compute Full Correlation Matrices

In theory, we could compute correlations between all pairs of grayordinates:

```
Full matrix: 91,282 x 91,282 = 8.3 BILLION values
Memory: 8.3e9 x 8 bytes = 66 GB!
```

This would crash most computers!

### The Solution: Sampling

The pipeline uses a **memory-efficient sampling approach**:

1. Sample ~500 grayordinates from each network
2. Compute within/between correlations from samples
3. This gives accurate estimates with tiny memory footprint

```{python}
#| label: memory-comparison
#| fig-cap: "Memory requirements comparison"

# Demonstrate the memory problem and solution
n_grayordinates_full = 91282

# Memory for full matrix
full_matrix_bytes = n_grayordinates_full ** 2 * 8  # 64-bit floats
full_matrix_gb = full_matrix_bytes / (1024**3)

# Memory for sampling approach
n_samples = 500
n_networks = 12
sampled_matrix_bytes = (n_samples * n_networks) ** 2 * 8
sampled_matrix_gb = sampled_matrix_bytes / (1024**3)

print("Memory Comparison")
print("=" * 50)
print(f"Full 91k x 91k matrix:")
print(f"  Elements: {n_grayordinates_full**2:,}")
print(f"  Memory: {full_matrix_gb:.1f} GB")
print(f"\nSampled approach (500 per network):")
print(f"  Elements: {(n_samples * n_networks)**2:,}")
print(f"  Memory: {sampled_matrix_gb:.3f} GB")
print(f"\nMemory reduction: {full_matrix_gb / sampled_matrix_gb:.0f}x smaller!")

# Visualize
fig, ax = plt.subplots(figsize=(8, 5))
bars = ax.bar(['Full Matrix\n(91,282^2)', 'Sampled\n(6,000^2)'],
              [full_matrix_gb, sampled_matrix_gb],
              color=['red', 'green'], alpha=0.7, edgecolor='black')
ax.set_ylabel('Memory (GB)', fontsize=12)
ax.set_title('Memory Requirements: Full vs Sampled Approach', fontsize=14)
ax.axhline(16, color='orange', linestyle='--', label='Typical laptop RAM (16 GB)')
ax.legend()

# Add labels
ax.text(0, full_matrix_gb + 2, f'{full_matrix_gb:.1f} GB', ha='center', fontsize=12)
ax.text(1, sampled_matrix_gb + 2, f'{sampled_matrix_gb:.3f} GB', ha='center', fontsize=12)

plt.tight_layout()
plt.show()
```

## 2.8 Key Takeaways

### Summary

1. **CIFTI** combines surface (cortex) and volume (subcortex) representations

2. **Grayordinates** are the universal index for all gray matter (~91k in HCP)

3. **Cole-Anticevic parcellation** assigns each grayordinate to one of 12 networks

4. Networks are categorized as **sensory-motor** or **association**

5. **Memory-efficient sampling** is essential for practical computation

### Connection to the Pipeline

In `run_segregation_python.py`:

- `load_cifti_data()` loads the .dtseries.nii file
- `load_atlas()` loads the .dlabel.nii parcellation
- `compute_network_segregation_efficient()` uses sampling to avoid memory issues
