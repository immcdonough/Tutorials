6  Motion Confounds and Group Comparisons

6.1 Learning Objectives

By the end of this lesson, you will:

  1. Understand why motion is THE critical confound in aging studies
  2. Know how to use FD as a covariate properly
  3. Understand run-level exclusion strategies
  4. Know best practices for reporting motion in publications

6.2 5.1 The Motion Problem in Aging Studies

6.2.1 Why This Matters for YOUR Study

Your study compares older adults vs younger adults. This is particularly vulnerable to motion confounds because:

  1. Older adults move more during scanning
  2. Motion artificially decreases segregation (inflates between-network correlations)
  3. Age differences in segregation might be motion artifacts!
The Confound Problem:

Age -> More Motion -> Lower Segregation (artifact)
Age -> Neural Changes -> Lower Segregation (real)

Without proper controls, you can't distinguish these!

In the validation you ran, you found:

6.3.1 What This Means

  • Subjects with higher motion show lower segregation

  • Group differences could be confounded by motion

6.4 5.3 Solution 1: FD as a Covariate (ANCOVA)

6.4.1 The ANCOVA Approach

Instead of: segregation ~ group

Use: segregation ~ group + mean_fd

This statistically controls for motion, asking:

“Do groups differ in segregation after accounting for their differences in motion?”

def ancova_analysis(seg_young, seg_old, fd_young, fd_old):
    """
    Perform ANCOVA: segregation ~ group + mean_fd

    Returns statistics for group effect with and without covariate.
    """
    from scipy.linalg import lstsq
    from scipy.stats import f as f_dist

    # Combine data
    all_seg = np.concatenate([seg_young, seg_old])
    all_fd = np.concatenate([fd_young, fd_old])
    all_group = np.concatenate([np.zeros(len(seg_young)), np.ones(len(seg_old))])

    results = {}

    # 1. Simple t-test (no covariate)
    t_raw, p_raw = ttest_ind(seg_young, seg_old)
    results['raw_t'] = t_raw
    results['raw_p'] = p_raw
    results['young_mean'] = np.mean(seg_young)
    results['old_mean'] = np.mean(seg_old)

    # Effect size (Cohen's d)
    pooled_std = np.sqrt(((len(seg_young)-1)*np.var(seg_young, ddof=1) +
                          (len(seg_old)-1)*np.var(seg_old, ddof=1)) /
                         (len(seg_young) + len(seg_old) - 2))
    results['raw_d'] = (np.mean(seg_young) - np.mean(seg_old)) / pooled_std

    # 2. ANCOVA (with FD covariate)
    # Full model: seg ~ intercept + group + fd
    X_full = np.column_stack([np.ones(len(all_seg)), all_group, all_fd])
    coef_full, _, _, _ = lstsq(X_full, all_seg)
    pred_full = X_full @ coef_full
    ss_resid_full = np.sum((all_seg - pred_full)**2)
    df_resid_full = len(all_seg) - 3

    # Reduced model: seg ~ intercept + fd (no group)
    X_reduced = np.column_stack([np.ones(len(all_seg)), all_fd])
    coef_reduced, _, _, _ = lstsq(X_reduced, all_seg)
    pred_reduced = X_reduced @ coef_reduced
    ss_resid_reduced = np.sum((all_seg - pred_reduced)**2)

    # F-test for group effect
    ss_group = ss_resid_reduced - ss_resid_full
    f_stat = (ss_group / 1) / (ss_resid_full / df_resid_full)
    p_ancova = 1 - f_dist.cdf(f_stat, 1, df_resid_full)

    results['ancova_f'] = f_stat
    results['ancova_p'] = p_ancova
    results['group_coef'] = coef_full[1]  # Group effect controlling for FD
    results['fd_coef'] = coef_full[2]     # FD effect

    return results

# Run ANCOVA on simulated data
results = ancova_analysis(obs_seg_young, obs_seg_old, fd_young, fd_old)

6.5 5.4 Solution 2: Run-Level Exclusion

6.5.1 The Problem with Subject-Level Exclusion

Traditional approach: If a subject has too much motion, exclude the entire subject.

Problem: This can bias your sample! Subjects with higher motion (often older adults) are disproportionately excluded.

6.5.2 Better Approach: Run-Level Exclusion

For multi-run tasks (like your encoding/retrieval with 3 runs each):

  1. Evaluate motion per run
  2. Exclude only bad runs, keep good ones
  3. Subject is included if they have >= 1 good run

This preserves more data while maintaining quality.

def check_motion_per_run(fd, vols_per_run, n_runs, threshold, max_censored):
    """
    Check motion criteria for each run separately.

    From segregation_utils.py
    """
    results = []

    for run_idx in range(n_runs):
        start = run_idx * vols_per_run
        end = min((run_idx + 1) * vols_per_run, len(fd))
        run_fd = fd[start:end]

        mean_fd = np.mean(run_fd)
        n_bad = np.sum(run_fd > threshold)
        prop_bad = n_bad / len(run_fd)

        passes = (mean_fd <= threshold) and (prop_bad <= max_censored)

        results.append({
            'run': run_idx + 1,
            'mean_fd': mean_fd,
            'prop_bad': prop_bad,
            'passes': passes,
        })

    return results

6.6 5.5 Reporting Motion in Publications

6.6.1 Required Elements

Reviewers for aging studies will expect:

  1. Motion statistics by group
  2. Statistical test for motion differences
  3. Motion-outcome correlation
  4. Description of motion handling
  5. Sensitivity analyses
def generate_motion_report(fd_young, fd_old, seg_young, seg_old):
    """
    Generate publication-ready motion statistics.
    """
    report = []
    report.append("="*70)
    report.append("MOTION QUALITY CONTROL REPORT")
    report.append("="*70)

    # 1. Descriptive statistics by group
    report.append("\n1. MOTION STATISTICS BY GROUP")
    report.append("-"*50)
    report.append(f"{'Group':<15} {'N':>6} {'Mean FD':>10} {'SD':>8} {'Range':>15}")
    report.append("-"*50)
    report.append(f"{'Young':<15} {len(fd_young):>6} {np.mean(fd_young):>10.3f} "
                  f"{np.std(fd_young):>8.3f} {np.min(fd_young):.2f}-{np.max(fd_young):.2f}")
    report.append(f"{'Older':<15} {len(fd_old):>6} {np.mean(fd_old):>10.3f} "
                  f"{np.std(fd_old):>8.3f} {np.min(fd_old):.2f}-{np.max(fd_old):.2f}")

    # 2. Group difference in motion
    t, p = ttest_ind(fd_young, fd_old)
    report.append(f"\n2. GROUP DIFFERENCE IN MOTION")
    report.append("-"*50)
    report.append(f"Independent samples t-test: t({len(fd_young)+len(fd_old)-2}) = {t:.3f}, p = {p:.4f}")
    if p < 0.05:
        report.append("-> SIGNIFICANT: Groups differ in motion. Covariate essential.")
    else:
        report.append("-> Not significant: Groups do not differ in motion.")

    # 3. Motion-segregation correlation
    all_fd = np.concatenate([fd_young, fd_old])
    all_seg = np.concatenate([seg_young, seg_old])
    r, p_corr = pearsonr(all_fd, all_seg)
    report.append(f"\n3. MOTION-SEGREGATION ASSOCIATION")
    report.append("-"*50)
    report.append(f"Pearson correlation: r = {r:.3f}, p = {p_corr:.4f}")
    if abs(r) > 0.3 and p_corr < 0.05:
        report.append("-> CONCERN: Significant motion-segregation correlation.")
    else:
        report.append("-> Motion-segregation correlation not significant.")

    # 4. Exclusion summary
    report.append(f"\n4. EXCLUSION CRITERIA")
    report.append("-"*50)
    report.append("* FD threshold: 0.3 mm")
    report.append("* Max censored proportion: 20%")
    report.append("* Scrubbing: 1 volume before, 2 volumes after high-motion")
    report.append("* Run-level exclusion for multi-run tasks")

    # 5. Recommendations
    report.append(f"\n5. STATISTICAL APPROACH")
    report.append("-"*50)
    report.append("Primary analysis: ANCOVA with mean FD as covariate")
    report.append("Model: segregation ~ group + mean_fd")
    report.append("\nSensitivity analyses:")
    report.append("  a) Results with and without FD covariate")
    report.append("  b) Stricter motion threshold (0.2 mm)")
    report.append("  c) Propensity score matching on motion")

    report.append("\n" + "="*70)

    return "\n".join(report)

# Generate report
report = generate_motion_report(fd_young, fd_old, obs_seg_young, obs_seg_old)
print(report)

6.7 5.6 Sensitivity Analyses

6.7.1 What Are Sensitivity Analyses?

Additional analyses that test whether your results are robust to:

  • Different motion thresholds
  • Different covariates
  • Different subsamples

These strengthen your paper by showing results aren’t artifacts of specific choices.

6.8 5.7 The Pipeline’s Approach

6.8.1 What the Pipeline Does

Your pipeline implements several motion-handling strategies:

  1. Confound regression (motion parameters, CompCor)
  2. Volume censoring (FD > 0.3 mm with padding)

    """
    Regress FD out of segregation to get FD-adjusted values.

## 5.1 The Motion Problem in Aging Studies

### Why This Matters for YOUR Study

Your study compares **older adults vs younger adults**. This is particularly vulnerable to motion confounds because:

1. **Older adults move more** during scanning
2. **Motion artificially decreases segregation** (inflates between-network correlations)
3. **Age differences in segregation might be motion artifacts!**

```
The Confound Problem:

Age -> More Motion -> Lower Segregation (artifact)
Age -> Neural Changes -> Lower Segregation (real)

Without proper controls, you can't distinguish these!
```

## 5.3 Solution 1: FD as a Covariate (ANCOVA)

### The ANCOVA Approach

Instead of: `segregation ~ group`

Use: `segregation ~ group + mean_fd`

This statistically controls for motion, asking:

> "Do groups differ in segregation **after accounting for their differences in motion**?"

```{python}
#| label: ancova-analysis
#| echo: true

def ancova_analysis(seg_young, seg_old, fd_young, fd_old):
    """
    Perform ANCOVA: segregation ~ group + mean_fd

    Returns statistics for group effect with and without covariate.
    """
    from scipy.linalg import lstsq
    from scipy.stats import f as f_dist

    # Combine data
    all_seg = np.concatenate([seg_young, seg_old])
    all_fd = np.concatenate([fd_young, fd_old])
    all_group = np.concatenate([np.zeros(len(seg_young)), np.ones(len(seg_old))])

    results = {}

    # 1. Simple t-test (no covariate)
    t_raw, p_raw = ttest_ind(seg_young, seg_old)
    results['raw_t'] = t_raw
    results['raw_p'] = p_raw
    results['young_mean'] = np.mean(seg_young)
    results['old_mean'] = np.mean(seg_old)

    # Effect size (Cohen's d)
    pooled_std = np.sqrt(((len(seg_young)-1)*np.var(seg_young, ddof=1) +
                          (len(seg_old)-1)*np.var(seg_old, ddof=1)) /
                         (len(seg_young) + len(seg_old) - 2))
    results['raw_d'] = (np.mean(seg_young) - np.mean(seg_old)) / pooled_std

    # 2. ANCOVA (with FD covariate)
    # Full model: seg ~ intercept + group + fd
    X_full = np.column_stack([np.ones(len(all_seg)), all_group, all_fd])
    coef_full, _, _, _ = lstsq(X_full, all_seg)
    pred_full = X_full @ coef_full
    ss_resid_full = np.sum((all_seg - pred_full)**2)
    df_resid_full = len(all_seg) - 3

    # Reduced model: seg ~ intercept + fd (no group)
    X_reduced = np.column_stack([np.ones(len(all_seg)), all_fd])
    coef_reduced, _, _, _ = lstsq(X_reduced, all_seg)
    pred_reduced = X_reduced @ coef_reduced
    ss_resid_reduced = np.sum((all_seg - pred_reduced)**2)

    # F-test for group effect
    ss_group = ss_resid_reduced - ss_resid_full
    f_stat = (ss_group / 1) / (ss_resid_full / df_resid_full)
    p_ancova = 1 - f_dist.cdf(f_stat, 1, df_resid_full)

    results['ancova_f'] = f_stat
    results['ancova_p'] = p_ancova
    results['group_coef'] = coef_full[1]  # Group effect controlling for FD
    results['fd_coef'] = coef_full[2]     # FD effect

    return results

# Run ANCOVA on simulated data
results = ancova_analysis(obs_seg_young, obs_seg_old, fd_young, fd_old)

print("ANCOVA Results: Does Age Affect Segregation?")
print("=" * 60)
print(f"\nDescriptive Statistics:")
print(f"  Young: M = {results['young_mean']:.4f}")
print(f"  Older: M = {results['old_mean']:.4f}")
print(f"\n1. WITHOUT FD Covariate (raw t-test):")
print(f"   t = {results['raw_t']:.3f}, p = {results['raw_p']:.4f}, d = {results['raw_d']:.3f}")
sig1 = "SIGNIFICANT" if results['raw_p'] < 0.05 else "Not significant"
print(f"   -> {sig1}")
print(f"\n2. WITH FD Covariate (ANCOVA):")
print(f"   F = {results['ancova_f']:.3f}, p = {results['ancova_p']:.4f}")
print(f"   Group coefficient: {results['group_coef']:.4f}")
print(f"   FD coefficient: {results['fd_coef']:.4f}")
sig2 = "SIGNIFICANT" if results['ancova_p'] < 0.05 else "Not significant"
print(f"   -> {sig2}")

print(f"\n" + "="*60)
print("INTERPRETATION:")
if results['raw_p'] < 0.05 and results['ancova_p'] >= 0.05:
    print("The age difference DISAPPEARS when controlling for motion!")
    print("This suggests the raw effect was a motion artifact.")
elif results['raw_p'] < 0.05 and results['ancova_p'] < 0.05:
    print("The age difference REMAINS after controlling for motion.")
    print("This suggests a true neural effect.")
elif results['raw_p'] >= 0.05 and results['ancova_p'] < 0.05:
    print("An age difference EMERGES after controlling for motion!")
    print("Motion was masking the true effect.")
else:
    print("No significant age difference with or without covariate.")
```

## 5.4 Solution 2: Run-Level Exclusion

### The Problem with Subject-Level Exclusion

Traditional approach: If a subject has too much motion, exclude the **entire subject**.

Problem: This can bias your sample! Subjects with higher motion (often older adults) are disproportionately excluded.

### Better Approach: Run-Level Exclusion

For multi-run tasks (like your encoding/retrieval with 3 runs each):

1. Evaluate motion **per run**
2. Exclude only **bad runs**, keep good ones
3. Subject is included if they have >= 1 good run

This preserves more data while maintaining quality.

```{python}
#| label: run-level-exclusion
#| fig-cap: "Run-level motion assessment"

def check_motion_per_run(fd, vols_per_run, n_runs, threshold, max_censored):
    """
    Check motion criteria for each run separately.

    From segregation_utils.py
    """
    results = []

    for run_idx in range(n_runs):
        start = run_idx * vols_per_run
        end = min((run_idx + 1) * vols_per_run, len(fd))
        run_fd = fd[start:end]

        mean_fd = np.mean(run_fd)
        n_bad = np.sum(run_fd > threshold)
        prop_bad = n_bad / len(run_fd)

        passes = (mean_fd <= threshold) and (prop_bad <= max_censored)

        results.append({
            'run': run_idx + 1,
            'mean_fd': mean_fd,
            'prop_bad': prop_bad,
            'passes': passes,
        })

    return results
```

## 5.5 Reporting Motion in Publications

### Required Elements

Reviewers for aging studies will expect:

1. **Motion statistics by group**

```{python}
#| label: motion-report
#| echo: true

def generate_motion_report(fd_young, fd_old, seg_young, seg_old):
    """
    Generate publication-ready motion statistics.
    """
    report = []
    report.append("="*70)
    report.append("MOTION QUALITY CONTROL REPORT")
    report.append("="*70)

    # 1. Descriptive statistics by group
    report.append("\n1. MOTION STATISTICS BY GROUP")
    report.append("-"*50)
    report.append(f"{'Group':<15} {'N':>6} {'Mean FD':>10} {'SD':>8} {'Range':>15}")
    report.append("-"*50)
    report.append(f"{'Young':<15} {len(fd_young):>6} {np.mean(fd_young):>10.3f} "
                  f"{np.std(fd_young):>8.3f} {np.min(fd_young):.2f}-{np.max(fd_young):.2f}")
    report.append(f"{'Older':<15} {len(fd_old):>6} {np.mean(fd_old):>10.3f} "
                  f"{np.std(fd_old):>8.3f} {np.min(fd_old):.2f}-{np.max(fd_old):.2f}")

    # 2. Group difference in motion
    t, p = ttest_ind(fd_young, fd_old)
    report.append(f"\n2. GROUP DIFFERENCE IN MOTION")
    report.append("-"*50)
    report.append(f"Independent samples t-test: t({len(fd_young)+len(fd_old)-2}) = {t:.3f}, p = {p:.4f}")
    if p < 0.05:
        report.append("-> SIGNIFICANT: Groups differ in motion. Covariate essential.")
    else:
        report.append("-> Not significant: Groups do not differ in motion.")

    # 3. Motion-segregation correlation
    all_fd = np.concatenate([fd_young, fd_old])
    all_seg = np.concatenate([seg_young, seg_old])
    r, p_corr = pearsonr(all_fd, all_seg)
    report.append(f"\n3. MOTION-SEGREGATION ASSOCIATION")
    report.append("-"*50)
    report.append(f"Pearson correlation: r = {r:.3f}, p = {p_corr:.4f}")
    if abs(r) > 0.3 and p_corr < 0.05:
        report.append("-> CONCERN: Significant motion-segregation correlation.")
    else:
        report.append("-> Motion-segregation correlation not significant.")

    # 4. Exclusion summary
    report.append(f"\n4. EXCLUSION CRITERIA")
    report.append("-"*50)
    report.append("* FD threshold: 0.3 mm")
    report.append("* Max censored proportion: 20%")
    report.append("* Scrubbing: 1 volume before, 2 volumes after high-motion")
    report.append("* Run-level exclusion for multi-run tasks")

    # 5. Recommendations
    report.append(f"\n5. STATISTICAL APPROACH")
    report.append("-"*50)
    report.append("Primary analysis: ANCOVA with mean FD as covariate")
    report.append("Model: segregation ~ group + mean_fd")
    report.append("\nSensitivity analyses:")
    report.append("  a) Results with and without FD covariate")
    report.append("  b) Stricter motion threshold (0.2 mm)")
    report.append("  c) Propensity score matching on motion")

    report.append("\n" + "="*70)

    return "\n".join(report)

# Generate report
report = generate_motion_report(fd_young, fd_old, obs_seg_young, obs_seg_old)
print(report)
```

## 5.7 The Pipeline's Approach

### What the Pipeline Does

Your pipeline implements several motion-handling strategies:

1. **Confound regression** (motion parameters, CompCor)
2. **Volume censoring** (FD > 0.3 mm with padding)
3. **Run-level exclusion** (for multi-run tasks)
4. **Mean FD in output** (for use as covariate)
5. **FD-adjusted segregation** (available in validation output)

### Key Output Files

| File | Contents |
|------|----------|
| `*_segregation_results.csv` | Includes `mean_fd` column |
| `*_fd_adjusted.csv` | FD-regressed segregation values |
| `validation_metrics.csv` | Motion-segregation correlation |

```{python}
#| label: fd-adjusted-segregation
#| fig-cap: "Raw vs FD-adjusted segregation"

# Demonstrate the FD-adjusted segregation calculation
def compute_fd_adjusted_segregation(segregation, fd):
    """
    Regress FD out of segregation to get FD-adjusted values.

    From run_validation.py
    """
    from scipy.linalg import lstsq

    # Design matrix: intercept + FD
    X = np.column_stack([np.ones(len(fd)), fd])

    # Fit regression
    coef, _, _, _ = lstsq(X, segregation)

    # Get residuals
    predicted = X @ coef
    residuals = segregation - predicted

    # Add back mean for interpretability
    adjusted = residuals + np.mean(segregation)

    return adjusted, coef

# Apply to our data
all_fd = np.concatenate([fd_young, fd_old])
all_seg = np.concatenate([obs_seg_young, obs_seg_old])
group_labels = ['Young'] * n_young + ['Older'] * n_old

adjusted_seg, coef = compute_fd_adjusted_segregation(all_seg, all_fd)
```

## 5.8 Key Takeaways

### Summary

1. **Motion is THE critical confound** in aging FC studies
   - Older adults move more
   - Motion artificially reduces segregation
   - Can create spurious age effects

2. **Always include FD as a covariate**
   - Use ANCOVA: `segregation ~ group + mean_fd`
   - Report results with and without covariate

3. **Run-level exclusion** preserves more data
   - Evaluate each run separately
   - Keep subjects with at least 1 good run

4. **Report thoroughly**
   - Motion by group
   - Motion-outcome correlation
   - Exclusion rates
   - Sensitivity analyses

### Checklist for Your Paper

- [ ] Report mean FD by group
- [ ] Test for group differences in motion
- [ ] Report motion-segregation correlation
- [ ] Include FD as covariate in primary analysis
- [ ] Report exclusion rates by group
- [ ] Run sensitivity analyses
- [ ] Show results hold with stricter thresholds
