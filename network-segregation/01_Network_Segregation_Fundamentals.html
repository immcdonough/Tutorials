2.2 1.1 Functional Connectivity: The Foundation

2.2.1 What is Functional Connectivity?

Functional connectivity (FC) measures the statistical dependence between brain regions’ activity over time. If two regions show correlated BOLD signals, they are considered “functionally connected.”

Region A: ~~~\/\/\/~~~\/\/\/~~~
Region B: ~~~\/\/\/~~~\/\/\/~~~  → High correlation (connected)
Region C: \/\/\/~~~\/\/\/~~~\/\  → Low correlation (not connected)

2.2.2 Why Correlation?

We use Pearson correlation because:

  • It’s scale-invariant (doesn’t matter if signal is stronger in one region)
  • Values range from -1 to +1 (easy to interpret)
  • Well-understood statistical properties

2.4 1.3 The Segregation Formula

2.4.1 What is Network Segregation?

Segregation quantifies how much a network’s internal connectivity exceeds its connectivity to other networks.

2.4.2 The Formula (Chan et al., 2014)

\[S = \frac{W - B}{W}\]

Where:

  • W = Mean Within-network correlation
  • B = Mean Between-network correlation
  • S = Segregation index

2.4.3 Interpretation

S Value Interpretation
S ≈ 1 Perfect segregation (W >> B)
S ≈ 0.5 Moderate segregation (W = 2B)
S ≈ 0 No segregation (W = B)
S < 0 Anti-segregation (B > W) - rare

2.4.4 Why This Formula?

  • Normalizes by within-network connectivity
  • Comparable across networks of different sizes
  • Intuitive: “What fraction of within-network connectivity is unique?”
def calculate_segregation(corr_matrix, network_assignments):
    """
    Calculate network segregation from a correlation matrix.

    This is the CORE function - understand this and you understand segregation!
    """
    # Make a copy and prepare the matrix
    M = corr_matrix.copy()
    np.fill_diagonal(M, 0)  # Remove self-connections
    M[M < 0] = 0  # Use only positive correlations

    # Fisher z-transform for proper averaging of correlations
    # arctanh(r) transforms correlations to a scale where averaging is valid
    M_z = np.arctanh(np.clip(M, -0.999, 0.999))

    networks = np.unique(network_assignments)
    networks = networks[networks > 0]  # Exclude background (0)

    within_edges = []
    between_edges = []

    for net in networks:
        # Find indices of regions in this network
        net_idx = np.where(network_assignments == net)[0]
        other_idx = np.where((network_assignments != net) & (network_assignments > 0))[0]

        # Collect within-network correlations (upper triangle only to avoid duplicates)
        for i in range(len(net_idx)):
            for j in range(i + 1, len(net_idx)):
                within_edges.append(M_z[net_idx[i], net_idx[j]])

        # Collect between-network correlations
        for i in net_idx:
            for j in other_idx:
                if i < j:  # Upper triangle only
                    between_edges.append(M_z[i, j])

    # Calculate means (back-transform from z)
    W = np.tanh(np.mean(within_edges)) if within_edges else np.nan
    B = np.tanh(np.mean(between_edges)) if between_edges else np.nan

    # Segregation
    S = (W - B) / W if W > 0 else np.nan

    return {'W': W, 'B': B, 'S': S}

# Calculate segregation for our simulated matrix
result = calculate_segregation(corr_matrix, network_labels)

2.5 1.4 Why Segregation Matters

2.5.1 Cognitive Implications

Network segregation reflects the brain’s ability to maintain specialized processing:

  • High segregation → Networks work independently → Specialized processing
  • Low segregation → Networks blur together → Less specialized

2.5.2 Segregation and Aging

This is particularly relevant for your older vs. younger adult study:

Finding Implication
Older adults show lower segregation Networks become less distinct with age
This correlates with cognitive decline Dedifferentiation hypothesis
Effect varies by network Association networks most affected

2.5.3 The Dedifferentiation Hypothesis

With aging, brain networks become less distinct (“dedifferentiated”):

  • Within-network connectivity may decrease
  • Between-network connectivity may increase
  • Result: Lower segregation
def create_network_matrix(within_corr, between_corr, n_regions=12, n_networks=3):
    """Create a correlation matrix with specified within/between correlations."""
    regions_per_net = n_regions // n_networks
    network_labels = np.repeat(np.arange(1, n_networks + 1), regions_per_net)

    M = np.zeros((n_regions, n_regions))
    for i in range(n_regions):
        for j in range(n_regions):
            if i == j:
                M[i, j] = 1.0
            elif network_labels[i] == network_labels[j]:
                M[i, j] = within_corr
            else:
                M[i, j] = between_corr
    return M, network_labels

2.6 1.5 The Fisher Z-Transform

2.6.1 Why Transform Correlations?

You may have noticed we used np.arctanh() (Fisher z-transform) before averaging correlations. Here’s why:

2.6.2 The Problem with Averaging Correlations Directly

Correlation values are bounded (-1 to +1), which creates problems:

  • The distribution is skewed near the bounds
  • A correlation of 0.9 is not “twice as strong” as 0.45
  • Averaging doesn’t work properly

2.6.3 The Solution: Fisher Z-Transform

\[z = \text{arctanh}(r) = \frac{1}{2} \ln\left(\frac{1+r}{1-r}\right)\]

This transforms correlations to an unbounded, normally distributed scale where:

  • Averaging is statistically valid
  • Standard errors are well-defined
# Visualize the Fisher z-transform
r_values = np.linspace(-0.99, 0.99, 100)
z_values = np.arctanh(r_values)

fig, axes = plt.subplots(1, 2, figsize=(12, 4))

# Plot transform
axes[0].plot(r_values, z_values, 'b-', linewidth=2)
axes[0].axhline(0, color='gray', linestyle='--', alpha=0.5)
axes[0].axvline(0, color='gray', linestyle='--', alpha=0.5)
axes[0].set_xlabel('Correlation (r)', fontsize=12)
axes[0].set_ylabel('Fisher z', fontsize=12)
axes[0].set_title('Fisher Z-Transform: r → z', fontsize=14)
axes[0].grid(True, alpha=0.3)

# Show why it matters for averaging
correlations = [0.3, 0.5, 0.8, 0.9]

# Wrong way: average correlations directly
wrong_avg = np.mean(correlations)

# Right way: transform, average, back-transform
z_transformed = np.arctanh(correlations)
z_avg = np.mean(z_transformed)
right_avg = np.tanh(z_avg)

x = np.arange(len(correlations) + 2)
values = correlations + [wrong_avg, right_avg]
labels = [f'r={c}' for c in correlations] + ['Wrong\nAvg', 'Fisher\nAvg']
colors = ['steelblue']*4 + ['red', 'green']

axes[1].bar(x, values, color=colors, alpha=0.7, edgecolor='black')
axes[1].set_xticks(x)
axes[1].set_xticklabels(labels)
axes[1].set_ylabel('Correlation', fontsize=12)
axes[1].set_title(f'Averaging Correlations\nWrong={wrong_avg:.3f}, Fisher={right_avg:.3f}', fontsize=14)
axes[1].axhline(wrong_avg, color='red', linestyle='--', alpha=0.5)
axes[1].axhline(right_avg, color='green', linestyle='--', alpha=0.5)

plt.tight_layout()

2.7 1.6 Key Takeaways

2.7.1 Summary

  1. Functional connectivity = correlation between brain regions’ timeseries

  2. Network segregation measures how distinct networks are: \[S = \frac{W - B}{W}\]

  3. Higher segregation → More specialized processing

  4. Aging is associated with decreased segregation (dedifferentiation)

  5. Fisher z-transform is essential for properly averaging correlations

2.7.2 Connection to the Pipeline

In segregation_utils.py, the calculate_segregation() function implements exactly what we covered:

  • Zeroing the diagonal (no self-connections)
  • Zeroing negative correlations (controversial but common)
  • Fisher z-transform before averaging
  • Back-transform to get final W, B, S values

## 1.3 The Segregation Formula

### What is Network Segregation?

**Segregation** quantifies how much a network's internal connectivity exceeds its connectivity to other networks.

### The Formula (Chan et al., 2014)

$$S = \frac{W - B}{W}$$

Where:

- **W** = Mean **W**ithin-network correlation
- **B** = Mean **B**etween-network correlation
- **S** = **S**egregation index

### Interpretation

| S Value | Interpretation |
|---------|---------------|
| S ≈ 1 | Perfect segregation (W >> B) |
| S ≈ 0.5 | Moderate segregation (W = 2B) |
| S ≈ 0 | No segregation (W = B) |
| S < 0 | Anti-segregation (B > W) - rare |

### Why This Formula?

- Normalizes by within-network connectivity
- Comparable across networks of different sizes
- Intuitive: "What fraction of within-network connectivity is unique?"

```{python}
#| label: segregation-calculation

def calculate_segregation(corr_matrix, network_assignments):
    """
    Calculate network segregation from a correlation matrix.

    This is the CORE function - understand this and you understand segregation!
    """
    # Make a copy and prepare the matrix
    M = corr_matrix.copy()
    np.fill_diagonal(M, 0)  # Remove self-connections
    M[M < 0] = 0  # Use only positive correlations

    # Fisher z-transform for proper averaging of correlations
    # arctanh(r) transforms correlations to a scale where averaging is valid
    M_z = np.arctanh(np.clip(M, -0.999, 0.999))

    networks = np.unique(network_assignments)
    networks = networks[networks > 0]  # Exclude background (0)

    within_edges = []
    between_edges = []

    for net in networks:
        # Find indices of regions in this network
        net_idx = np.where(network_assignments == net)[0]
        other_idx = np.where((network_assignments != net) & (network_assignments > 0))[0]

        # Collect within-network correlations (upper triangle only to avoid duplicates)
        for i in range(len(net_idx)):
            for j in range(i + 1, len(net_idx)):
                within_edges.append(M_z[net_idx[i], net_idx[j]])

        # Collect between-network correlations
        for i in net_idx:
            for j in other_idx:
                if i < j:  # Upper triangle only
                    between_edges.append(M_z[i, j])

    # Calculate means (back-transform from z)
    W = np.tanh(np.mean(within_edges)) if within_edges else np.nan
    B = np.tanh(np.mean(between_edges)) if between_edges else np.nan

    # Segregation
    S = (W - B) / W if W > 0 else np.nan

    return {'W': W, 'B': B, 'S': S}

# Calculate segregation for our simulated matrix
result = calculate_segregation(corr_matrix, network_labels)

print("Segregation Analysis Results")
print("=" * 40)
print(f"Within-network connectivity (W):  {result['W']:.4f}")
print(f"Between-network connectivity (B): {result['B']:.4f}")
print(f"Segregation index (S):            {result['S']:.4f}")
print()
print(f"Interpretation: {result['S']*100:.1f}% of within-network")
print(f"connectivity is 'unique' to the network")
```

## 1.4 Why Segregation Matters

### Cognitive Implications

Network segregation reflects the brain's ability to maintain **specialized processing**:

- **High segregation** → Networks work independently → Specialized processing
- **Low segregation** → Networks blur together → Less specialized

### Segregation and Aging

This is particularly relevant for your older vs. younger adult study:

| Finding | Implication |
|---------|------------|
| Older adults show **lower** segregation | Networks become less distinct with age |
| This correlates with cognitive decline | Dedifferentiation hypothesis |
| Effect varies by network | Association networks most affected |

### The Dedifferentiation Hypothesis

With aging, brain networks become less distinct ("dedifferentiated"):

- Within-network connectivity may decrease
- Between-network connectivity may increase
- Result: Lower segregation

## 1.5 The Fisher Z-Transform

### Why Transform Correlations?

You may have noticed we used `np.arctanh()` (Fisher z-transform) before averaging correlations. Here's why:

### The Problem with Averaging Correlations Directly

Correlation values are **bounded** (-1 to +1), which creates problems:

- The distribution is skewed near the bounds
- A correlation of 0.9 is not "twice as strong" as 0.45
- Averaging doesn't work properly

### The Solution: Fisher Z-Transform

$$z = \text{arctanh}(r) = \frac{1}{2} \ln\left(\frac{1+r}{1-r}\right)$$

This transforms correlations to an **unbounded, normally distributed** scale where:

- Averaging is statistically valid
- Standard errors are well-defined

```{python}
#| label: fig-fisher-transform
#| fig-cap: "Fisher Z-Transform and Its Effect on Averaging"

# Visualize the Fisher z-transform
r_values = np.linspace(-0.99, 0.99, 100)
z_values = np.arctanh(r_values)

fig, axes = plt.subplots(1, 2, figsize=(12, 4))

axes[0].axhline(0, color='gray', linestyle='--', alpha=0.5)
axes[0].axvline(0, color='gray', linestyle='--', alpha=0.5)

axes[0].set_ylabel('Fisher z', fontsize=12)
```

## 1.6 Key Takeaways

### Summary

1. **Functional connectivity** = correlation between brain regions' timeseries

2. **Network segregation** measures how distinct networks are:
   $$S = \frac{W - B}{W}$$

3. **Higher segregation** → More specialized processing

4. **Aging** is associated with **decreased segregation** (dedifferentiation)

5. **Fisher z-transform** is essential for properly averaging correlations

### Connection to the Pipeline

In `segregation_utils.py`, the `calculate_segregation()` function implements exactly what we covered:

- Zeroing the diagonal (no self-connections)
- Zeroing negative correlations (controversial but common)
- Fisher z-transform before averaging
- Back-transform to get final W, B, S values
