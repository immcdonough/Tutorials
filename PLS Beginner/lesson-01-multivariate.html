Understanding the problem PLS solves

Learning Objectives

By the end of this lesson, you will understand:

  1. Why simple correlations fail with many variables
  2. The concept of latent variables (hidden patterns)
  3. The difference between correlation and covariance
  4. What it means to find optimal weighted combinations

The Problem with Many Variables

A Simple Example First

Imagine you measure two things on 50 students:

  • Hours studied
  • Exam score

Finding the relationship is easy: compute the correlation.

Code 
library(ggplot2)
set.seed(42)

# Simple two-variable case
n <- 50
hours <- runif(n, 1, 10)
score <- 50 + 4 * hours + rnorm(n, sd = 8)

df <- data.frame(hours = hours, score = score)

ggplot(df, aes(x = hours, y = score)) +
  geom_point(size = 3, alpha = 0.7) +
  geom_smooth(method = "lm", se = TRUE, color = "blue") +
  labs(title = "Simple Relationship",
       subtitle = sprintf("r = %.2f", cor(hours, score)),
       x = "Hours Studied", y = "Exam Score") +
  theme_minimal(base_size = 14)

One correlation. One relationship. Easy.

Now Make It Harder

But what if you measure:

  • 10 study behaviors: hours, breaks, note-taking, practice tests, etc.
  • 8 outcomes: multiple exam scores, project grades, participation, etc.

Now you have 10 × 8 = 80 correlations to examine!

Code 
set.seed(42)

# Simulate multiple variables
n <- 50
p1 <- 10  # Study behaviors
p2 <- 8   # Outcomes

X <- matrix(rnorm(n * p1), n, p1)
Y <- matrix(rnorm(n * p2), n, p2)

# Add some real relationships
Y[, 1:3] <- Y[, 1:3] + 0.5 * X[, 1:3]  # Some behaviors predict some outcomes

# Compute all correlations
cor_matrix <- cor(X, Y)

# Visualize
cor_df <- expand.grid(
  StudyBehavior = paste0("Behavior", 1:p1),
  Outcome = paste0("Outcome", 1:p2)
)
cor_df$correlation <- as.vector(cor_matrix)

ggplot(cor_df, aes(x = Outcome, y = StudyBehavior, fill = correlation)) +
  geom_tile(color = "white") +
  geom_text(aes(label = sprintf("%.2f", correlation)), size = 3) +
  scale_fill_gradient2(low = "#4575b4", mid = "white", high = "#d73027",
                       midpoint = 0, limits = c(-1, 1)) +
  labs(title = "80 Correlations to Examine",
       subtitle = "Which ones matter? Is there a pattern?") +
  theme_minimal() +
  theme(axis.text.x = element_text(angle = 45, hjust = 1))

The Problems Multiply

With 80 correlations:

  1. Multiple testing: By chance, some will be “significant” even if nothing is real
  2. Redundancy: Many variables measure similar things
  3. No big picture: Hard to see if there’s an underlying pattern
  4. Overfitting: Easy to find spurious relationships
ImportantThe Core Problem

We don’t want 80 separate relationships. We want to know:

Is there a pattern of study behaviors that relates to a pattern of outcomes?

The Idea of Latent Variables

What is a Latent Variable?

A latent variable is a hidden factor that you don’t measure directly but that influences the things you do measure.

Example: You don’t measure “intelligence” directly. Instead, you measure: - Vocabulary test score - Math test score - Pattern recognition score

“Intelligence” is a latent variable that influences all three observed scores.

PLS Finds Latent Variables in TWO Sets

PLS goes further. It finds latent variables that:

  1. Explain variation within each variable set
  2. Are maximally related to each other between sets

Correlation vs Covariance

Why Does This Matter?

PLS can maximize either correlation or covariance between latent variables. Understanding the difference is crucial.

Correlation

Correlation measures the strength of a linear relationship, ignoring scale.

  • Ranges from -1 to +1
  • Unaffected by units (inches vs centimeters)
  • Height in inches vs height in cm have r = 1.0

\[r = \frac{\text{Cov}(X, Y)}{\text{SD}(X) \times \text{SD}(Y)}\]

Covariance

Covariance measures how variables move together, considering their scales.

  • Can be any value (positive or negative)
  • Larger when variables have more variance
  • Affected by units

\[\text{Cov}(X, Y) = \frac{1}{n-1} \sum_{i=1}^{n} (X_i - \bar{X})(Y_i - \bar{Y})\]

Visual Comparison

Code 
set.seed(42)
library(patchwork)

# Same correlation, different covariances
n <- 100

# Small variance
x1 <- rnorm(n, 0, 1)
y1 <- 0.7 * x1 + rnorm(n, 0, 0.7)

# Large variance (same correlation!)
x2 <- rnorm(n, 0, 5)
y2 <- 0.7 * x2 + rnorm(n, 0, 3.5)

p1 <- ggplot(data.frame(x = x1, y = y1), aes(x, y)) +
  geom_point(alpha = 0.6) +
  geom_smooth(method = "lm", se = FALSE, color = "blue") +
  xlim(-15, 15) + ylim(-15, 15) +
  labs(title = "Small Variance",
       subtitle = sprintf("r = %.2f, Cov = %.2f", cor(x1, y1), cov(x1, y1))) +
  theme_minimal() +
  coord_fixed()

p2 <- ggplot(data.frame(x = x2, y = y2), aes(x, y)) +
  geom_point(alpha = 0.6) +
  geom_smooth(method = "lm", se = FALSE, color = "blue") +
  xlim(-15, 15) + ylim(-15, 15) +
  labs(title = "Large Variance",
       subtitle = sprintf("r = %.2f, Cov = %.2f", cor(x2, y2), cov(x2, y2))) +
  theme_minimal() +
  coord_fixed()

p1 + p2 + plot_annotation(
  title = "Same Correlation, Different Covariance",
  subtitle = "Covariance captures both relationship strength AND variance"
)
NotePLS and Covariance

Standard PLS maximizes covariance, which means it finds patterns that:

  1. Have strong relationships (high correlation)
  2. Explain substantial variance in the data

This often gives more interpretable results than maximizing correlation alone.

Weighted Combinations

What is a Weighted Combination?

Instead of looking at variables individually, we combine them:

\[\text{Score} = w_1 \times \text{Var}_1 + w_2 \times \text{Var}_2 + w_3 \times \text{Var}_3 + ...\]

The weights (w) determine how much each variable contributes.

A Concrete Example

Suppose you measure study behaviors:

Student Hours Practice Tests Notes Pages
A 5 3 10
B 8 5 15
C 3 1 5

A weighted “study intensity” score might be:

\[\text{Study Intensity} = 0.4 \times \text{Hours} + 0.5 \times \text{Practice} + 0.1 \times \text{Notes}\]

For Student A: 0.4(5) + 0.5(3) + 0.1(10) = 2.0 + 1.5 + 1.0 = 4.5

Why Weights Matter

Different weights emphasize different aspects:

Code 
# Example with different weights
students <- data.frame(
  Student = LETTERS[1:10],
  Hours = c(5, 8, 3, 7, 6, 4, 9, 2, 6, 5),
  Practice = c(3, 5, 1, 4, 3, 2, 6, 1, 4, 3),
  Notes = c(10, 15, 5, 8, 12, 20, 10, 3, 8, 15)
)

# Two different weighting schemes
students$Score_Hours <- with(students, 0.8 * Hours + 0.1 * Practice + 0.1 * Notes)
students$Score_Balanced <- with(students, 0.33 * Hours + 0.33 * Practice + 0.33 * Notes)

# Compare
library(tidyr)
scores_long <- pivot_longer(students,
                             cols = c(Score_Hours, Score_Balanced),
                             names_to = "Weighting",
                             values_to = "Score")
scores_long$Weighting <- ifelse(scores_long$Weighting == "Score_Hours",
                                 "Heavy on Hours (0.8, 0.1, 0.1)",
                                 "Balanced (0.33, 0.33, 0.33)")

ggplot(scores_long, aes(x = Student, y = Score, fill = Weighting)) +
  geom_bar(stat = "identity", position = "dodge") +
  scale_fill_manual(values = c("#4575b4", "#d73027")) +
  labs(title = "Same Data, Different Weights = Different Scores",
       subtitle = "PLS finds the weights that maximize covariance with the other variable set",
       y = "Weighted Score") +
  theme_minimal(base_size = 14)

PLS Finds Optimal Weights

The key insight: PLS finds the weights that create scores with maximum covariance between the two variable sets.

You don’t choose the weights - the algorithm discovers them from the data!

Putting It All Together

What PLS Does (Conceptually)

  1. Takes two variable sets (e.g., brain and behavior)

  2. Finds weights for each variable in each set

  3. Creates latent variables (weighted combinations)

  4. Optimizes so the latent variables have maximum covariance

  5. Repeats to find additional, orthogonal patterns

Visual Summary

Key Takeaways

TipSummary

  1. The problem: Many variables create too many correlations to interpret

  2. The solution: Find weighted combinations (latent variables) that capture the essential relationships

  3. PLS approach: Maximize covariance between latent variables from two different datasets

  4. Why covariance: It balances relationship strength with variance explained

  5. The weights: These tell you which original variables matter most for the pattern

## Correlation vs Covariance

### Why Does This Matter?

PLS can maximize either **correlation** or **covariance** between latent variables. Understanding the difference is crucial.

### Correlation

**Correlation** measures the *strength* of a linear relationship, ignoring scale.

- Ranges from -1 to +1
- Unaffected by units (inches vs centimeters)
- Height in inches vs height in cm have r = 1.0

$$r = \frac{\text{Cov}(X, Y)}{\text{SD}(X) \times \text{SD}(Y)}$$

### Covariance

**Covariance** measures how variables *move together*, considering their scales.

- Can be any value (positive or negative)
- Larger when variables have more variance
- Affected by units

$$\text{Cov}(X, Y) = \frac{1}{n-1} \sum_{i=1}^{n} (X_i - \bar{X})(Y_i - \bar{Y})$$

## Weighted Combinations

### What is a Weighted Combination?

Instead of looking at variables individually, we combine them:

$$\text{Score} = w_1 \times \text{Var}_1 + w_2 \times \text{Var}_2 + w_3 \times \text{Var}_3 + ...$$

The **weights** (w) determine how much each variable contributes.

### A Concrete Example

Suppose you measure study behaviors:

| Student | Hours | Practice Tests | Notes Pages |
|---------|-------|----------------|-------------|
| A | 5 | 3 | 10 |
| B | 8 | 5 | 15 |
| C | 3 | 1 | 5 |

A weighted "study intensity" score might be:

$$\text{Study Intensity} = 0.4 \times \text{Hours} + 0.5 \times \text{Practice} + 0.1 \times \text{Notes}$$

For Student A: 0.4(5) + 0.5(3) + 0.1(10) = 2.0 + 1.5 + 1.0 = **4.5**

### Why Weights Matter

Different weights emphasize different aspects:

## Putting It All Together

### What PLS Does (Conceptually)

1. **Takes two variable sets** (e.g., brain and behavior)

2. **Finds weights** for each variable in each set

3. **Creates latent variables** (weighted combinations)

4. **Optimizes** so the latent variables have maximum covariance

5. **Repeats** to find additional, orthogonal patterns

## Key Takeaways

::: {.callout-tip}
## Summary

1. **The problem**: Many variables create too many correlations to interpret

2. **The solution**: Find weighted combinations (latent variables) that capture the essential relationships

3. **PLS approach**: Maximize covariance between latent variables from two different datasets

4. **Why covariance**: It balances relationship strength with variance explained

5. **The weights**: These tell you which original variables matter most for the pattern
:::
