Understanding what PLS actually computes

Learning Objectives

By the end of this lesson, you will understand:

  1. How PLS uses the cross-covariance matrix
  2. What Singular Value Decomposition (SVD) does
  3. The meaning of saliences, scores, and singular values
  4. How PLS finds multiple latent variables

The Cross-Covariance Matrix

Starting Point: Two Data Matrices

We have:

  • X: Brain data (n subjects × p brain variables)
  • Y: Behavior data (n subjects × q behavior variables)

Both matrices have the same subjects in rows.

Code 
library(ggplot2)
library(patchwork)
set.seed(42)

# Create example data
n <- 30  # subjects
p <- 5   # brain variables
q <- 3   # behavior variables

# Generate data with a real relationship
X <- matrix(rnorm(n * p), n, p)
colnames(X) <- paste0("Brain", 1:p)

# Y is related to X through a latent pattern
latent <- X[, 1] - X[, 2]  # True latent variable
Y <- matrix(rnorm(n * q), n, q)
Y[, 1] <- Y[, 1] + 0.8 * latent  # Behavior 1 related to latent
Y[, 2] <- Y[, 2] + 0.5 * latent  # Behavior 2 somewhat related
colnames(Y) <- paste0("Behav", 1:q)

What R Tells Us

  • Each entry R[i,j] = covariance between brain variable i and behavior variable j
  • Positive values: variables tend to increase together
  • Negative values: one increases as the other decreases
  • Near zero: little linear relationship
NoteThe Problem

R has p × q entries (5 × 3 = 15 in our example). We want to find the single best pattern that captures the most important relationship.

Singular Value Decomposition (SVD)

The Magic Tool

SVD is a mathematical technique that decomposes any matrix into three parts:

\[R = U \cdot S \cdot V^T\]

Where:

  • U: Left singular vectors (weights for X variables) - called “brain saliences”
  • S: Singular values (diagonal matrix of pattern strengths)
  • V: Right singular vectors (weights for Y variables) - called “behavior saliences”
Code 
# Perform SVD on the cross-covariance matrix
svd_result <- svd(R)

# Extract components
U <- svd_result$u  # Brain saliences
S <- svd_result$d  # Singular values
V <- svd_result$v  # Behavior saliences

cat("U (brain saliences):", dim(U), "\n")
U (brain saliences): 5 3
Code 
cat("S (singular values):", length(S), "values\n")
S (singular values): 3 values
Code 
cat("V (behavior saliences):", dim(V), "\n")
V (behavior saliences): 3 3

The Complete PLS Process

Step-by-Step Summary

In Code

Code 
# Complete PLS implementation
pls_simple <- function(X, Y) {
  # Step 1-2: Mean center
  X_c <- scale(X, center = TRUE, scale = FALSE)
  Y_c <- scale(Y, center = TRUE, scale = FALSE)

  # Step 3: Cross-covariance matrix
  n <- nrow(X)
  R <- t(X_c) %*% Y_c / (n - 1)

  # Step 4: SVD
  svd_result <- svd(R)

  # Step 5: Compute scores
  brain_scores <- X_c %*% svd_result$u
  behavior_scores <- Y_c %*% svd_result$v

  list(
    u = svd_result$u,           # Brain saliences
    v = svd_result$v,           # Behavior saliences
    s = svd_result$d,           # Singular values
    brain_scores = brain_scores,
    behavior_scores = behavior_scores
  )
}

# Run it
result <- pls_simple(X, Y)

cat("PLS Results:\n")
PLS Results:
Code 
cat("Singular values:", round(result$s, 3), "\n")
Singular values: 2.026 0.423 0.198
Code 
cat("Variance explained:", round((result$s^2)/sum(result$s^2)*100, 1), "%\n")
Variance explained: 95 4.1 0.9 %

What Makes PLS Special?

The Optimization Problem

PLS solves:

\[\max_{u, v} \text{Cov}(Xu, Yv)\]

Subject to: \(||u|| = 1\) and \(||v|| = 1\)

In words: Find unit-length weight vectors that maximize the covariance of the resulting scores.

Why SVD Solves This

Mathematical fact: The first left/right singular vectors of R are exactly the weight vectors that maximize this covariance!

This is why PLS is so elegant - a complex optimization problem has a simple, efficient solution.

Key Terminology Summary

Term Symbol Meaning
Saliences U, V Weights for original variables
Singular values S Strength of each LV pattern
Scores XU, YV Subject-level expression of pattern
Latent variable LV The weighted combination/pattern
Cross-covariance R Matrix of all X-Y covariances

Summary

TipKey Takeaways

  1. Cross-covariance matrix R captures all pairwise relationships

  2. SVD decomposes R into patterns ordered by importance

  3. Saliences are optimal weights that maximize covariance

  4. Singular values indicate pattern strength

  5. Scores show how each subject expresses each pattern

  6. Multiple orthogonal LVs capture independent patterns

### In Code

```{r}
#| label: full-pls

# Complete PLS implementation
pls_simple <- function(X, Y) {
  # Step 1-2: Mean center
  X_c <- scale(X, center = TRUE, scale = FALSE)
  Y_c <- scale(Y, center = TRUE, scale = FALSE)

  # Step 3: Cross-covariance matrix
  n <- nrow(X)
  R <- t(X_c) %*% Y_c / (n - 1)

  # Step 4: SVD
  svd_result <- svd(R)

  # Step 5: Compute scores
  brain_scores <- X_c %*% svd_result$u
  behavior_scores <- Y_c %*% svd_result$v

  list(
    u = svd_result$u,           # Brain saliences
    v = svd_result$v,           # Behavior saliences
    s = svd_result$d,           # Singular values
    brain_scores = brain_scores,
    behavior_scores = behavior_scores
  )
}

# Run it
result <- pls_simple(X, Y)

cat("PLS Results:\n")
cat("Singular values:", round(result$s, 3), "\n")
cat("Variance explained:", round((result$s^2)/sum(result$s^2)*100, 1), "%\n")
```

## What Makes PLS Special?

### The Optimization Problem

PLS solves:

$$\max_{u, v} \text{Cov}(Xu, Yv)$$

Subject to: $||u|| = 1$ and $||v|| = 1$

In words: Find unit-length weight vectors that maximize the covariance of the resulting scores.

### Why SVD Solves This

Mathematical fact: The **first left/right singular vectors** of R are exactly the weight vectors that maximize this covariance!

This is why PLS is so elegant - a complex optimization problem has a simple, efficient solution.

## Key Terminology Summary

| Term | Symbol | Meaning |
|------|--------|---------|
| **Saliences** | U, V | Weights for original variables |
| **Singular values** | S | Strength of each LV pattern |
| **Scores** | XU, YV | Subject-level expression of pattern |
| **Latent variable** | LV | The weighted combination/pattern |
| **Cross-covariance** | R | Matrix of all X-Y covariances |

::: {.callout-tip}
## Key Takeaways

1. **Cross-covariance matrix** R captures all pairwise relationships

2. **SVD** decomposes R into patterns ordered by importance

3. **Saliences** are optimal weights that maximize covariance

4. **Singular values** indicate pattern strength

5. **Scores** show how each subject expresses each pattern

6. Multiple **orthogonal LVs** capture independent patterns
:::
