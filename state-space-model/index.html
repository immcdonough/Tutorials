JOL Internal Feedback Pipeline: A Practical Course

Computational metacognition, state-space modeling, and fMRI analysis

What This Course Is

This is a five-lesson course built directly from the code in the JOL computation pipeline. Each lesson explains why the code is designed the way it is, shows you the actual implementation, and gives you runnable examples you can modify in your browser.

The pipeline answers one scientific question: How do people build and update internal beliefs about their own learning performance, without any external feedback?

The Big Picture

Participants study paired images (face-scene or face-object) and after each pair judge how likely they are to remember it later — a Judgment of Learning (JOL). There is no feedback. Then, in a later memory test, we see what they actually recalled.

The pipeline models this as a genuine feedback loop: internal states generate predictions, observations violate those predictions (creating errors), and those errors update the states. This loop is the computational engine of metacognition.

     JOL observation
          ↓
    Prediction Error  ←──── State at time t
     (JOL − State)               ↑
          ↓                      │
     Update Rule ────────────────┘
   S_t = S_{t-1} + α × PE_{t-1}

This loop-based view — inspired by Nicole Rust’s work on neural feedback — is what separates this analysis from a simple GLM of confidence ratings.

Key Equations Reference

State transition (delta rule): \[S_t^{(c)} = S_{t-1}^{(c)} + \alpha \cdot \underbrace{(JOL_{t-1} - S_{t-1}^{(c)})}_{\text{Prediction Error}_{t-1}}\]

Prediction error: \[PE_t = JOL_t - S_t\]

Critical identity (causes collinearity — Lesson 4): \[JOL_t = S_t + PE_t \quad \forall t\]

Metacognitive efficiency (Lesson 3): \[M\text{-ratio} = \frac{\text{meta-}d'}{d'}\]
