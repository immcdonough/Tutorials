Lesson 1: The Internal Feedback Loop

State-space modeling of metacognitive expectations

All code cells are interactive. Click ▶ Run to execute. Python loads in-browser via Pyodide — first run takes ~15 s while packages download.

Learning Objectives

  1. Understand the delta-rule state-space model and why it captures an internal feedback loop
  2. Know the three variables — State, JOL, PE — and the algebraic relationship that binds them
  3. Simulate state trajectories and prediction errors from scratch
  4. Understand why S0 must be the first-trial JOL, not the mean

1.1 Why a Feedback Loop?

In most fMRI memory studies, parametric modulators are static stimulus properties. This pipeline takes a different approach: the regressors are outputs of a dynamical system that evolves over the experiment.

Participants form expectations. After ten face-scene pairs you have a sense of how well you’re learning. When a new pair surprises you — much easier or harder than expected — that surprise is a prediction error: the gap between what happened and what your internal model predicted.

This maps onto the delta-rule, adapted for metacognition where:

  • The state \(S_t^{(c)}\) is a running estimate of learning quality for category \(c\)
  • The observation is the JOL (1=Unlikely, 2=Maybe, 3=Likely)
  • There is no external feedback — the loop is entirely internal

1.2 The Model Equations

Transition equation: \[S_t^{(c)} = S_{t-1}^{(c)} + \alpha \cdot \underbrace{(JOL_{t-1} - S_{t-1}^{(c)})}_{\text{PE}_{t-1}}\]

Prediction error: \[PE_t = JOL_t - S_t^{(c)}\]

\(\alpha \in (0,1)\) is the learning rate. High \(\alpha\) = rapid adaptation; low \(\alpha\) = stable slow-moving expectation. States are tracked separately per category, one shared \(\alpha\) per participant.

1.4 The Critical Identity: JOL = State + PE


This is the most important algebraic fact in the entire pipeline. It holds by construction at every trial:


\[JOL_t \equiv S_t + PE_t\]

1.7 What Alpha Means Psychologically






Alpha
Meaning
Participant profile






≈ 0.05
Very slow updater
Expectations barely move




≈ 0.20
Moderate updater
State tracks gradual trends




≈ 0.50
Fast updater
State follows recent 2–3 trials




≈ 0.90
Near-unit updater
State ≈ last JOL






Real dataset: mean α = 0.188, median = 0.155. Older adults tend toward lower α, but the age correlation (r = 0.13) is not significant. JOL transition rate is the stronger age predictor (r = −0.36) — covered in Lesson 5.
