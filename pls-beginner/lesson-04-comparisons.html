The Method Landscape

Several methods relate two sets of variables. Understanding their differences helps you choose wisely.

Code 
library(ggplot2)
library(patchwork)
library(MASS)  # For CCA via cancor
set.seed(42)

# Create common dataset for all comparisons
n <- 100
p <- 8   # X variables
q <- 4   # Y variables

# Generate correlated data
Sigma <- matrix(0.3, p + q, p + q)
diag(Sigma) <- 1
# Make X and Y blocks more correlated internally
Sigma[1:p, 1:p] <- 0.4
diag(Sigma[1:p, 1:p]) <- 1
Sigma[(p+1):(p+q), (p+1):(p+q)] <- 0.4
diag(Sigma[(p+1):(p+q), (p+1):(p+q)]) <- 1
# Create cross-correlation
Sigma[1:3, (p+1):(p+2)] <- 0.5
Sigma[(p+1):(p+2), 1:3] <- 0.5

data <- mvrnorm(n, rep(0, p + q), Sigma)
X <- data[, 1:p]
Y <- data[, (p+1):(p+q)]
colnames(X) <- paste0("X", 1:p)
colnames(Y) <- paste0("Y", 1:q)

Canonical Correlation Analysis (CCA)

What CCA Does

CCA finds linear combinations of X and Y that have maximum correlation (not covariance).

\[\max_{a, b} \text{Corr}(Xa, Yb)\]

Subject to the combinations having unit variance.

CCA Algorithm

CCA Strengths and Limitations

TipCCA Strengths
  • Finds maximum correlation between variable sets
  • Scale-invariant: unaffected by variable units
  • Well-established statistical properties
  • Clear interpretation as correlation
WarningCCA Limitations
  • Requires n > p + q: Needs more observations than total variables
  • Sensitive to multicollinearity: Unstable when variables are highly correlated
  • Ignores variance: May find correlations in low-variance directions
  • Can be unreliable with high-dimensional data

Principal Component Regression (PCR)

What PCR Does

PCR is a two-step process:

  1. Perform PCA on X to get components
  2. Regress Y on the PCA components

PCR Implementation

Code 
# PCR implementation
# Step 1: PCA on X
pca_X <- prcomp(X, center = TRUE, scale. = TRUE)

# Step 2: Regress Y on first k components
k <- 3  # Number of components
pc_scores <- pca_X$x[, 1:k]

# Regression
pcr_model <- lm(Y[, 1] ~ pc_scores)

cat("PCR Results (predicting Y1):\n")
PCR Results (predicting Y1):
Code 
cat("============================\n")
============================
Code 
cat("Variance explained by first", k, "PCs:",
    round(sum(pca_X$sdev[1:k]^2) / sum(pca_X$sdev^2) * 100, 1), "%\n")
Variance explained by first 3 PCs: 67.9 %
Code 
cat("R² of regression:", round(summary(pcr_model)$r.squared, 3), "\n")
R² of regression: 0.359

The PCR Problem

PCR finds directions that explain variance in X, not relationships with Y.

Code 
# Create extreme example
set.seed(456)
n <- 100

# X1 has high variance but no relation to Y
# X2 has low variance but strong relation to Y
X_demo <- cbind(
  X1 = rnorm(n, sd = 10),  # High variance, unrelated
  X2 = rnorm(n, sd = 1)    # Low variance
)
Y_demo <- 2 * X_demo[, 2] + rnorm(n, sd = 0.5)  # Y depends on X2!

# PCA picks X1 first
pca_demo <- prcomp(X_demo, center = TRUE, scale. = FALSE)

# PCR with 1 component (will use mostly X1)
pc1 <- pca_demo$x[, 1]
pcr_r2 <- cor(pc1, Y_demo)^2

# Compare to using X2 directly
direct_r2 <- cor(X_demo[, 2], Y_demo)^2

cat("PCA loadings (PC1):\n")

ImportantKey Insight

PLS beats PCR when the directions of maximum variance in X are not the most predictive of Y. PLS explicitly looks for X directions that relate to Y.

Reduced Rank Regression (RRR)

What RRR Does

RRR finds the best low-rank approximation to the regression coefficient matrix:

\[Y = XB + E, \quad \text{where } B \text{ has rank } k\]

It’s a compromise between full regression and PCA-style dimension reduction.

Relationship to PLS

RRR can be viewed as finding the same subspace as PLS, but:

  • RRR minimizes prediction error
  • PLS maximizes covariance

For standardized data, they often give similar results.

Comprehensive Comparison

Comprehensive Method Comparison
Method Optimizes Sample Requirement Uses Y in weights? Best For
CCA Correlation n > p + q Yes Low-dim, correlation focus
PLS-C Covariance Any Yes Pattern discovery, high-dim
PLS-R Covariance → Prediction Any Yes Prediction, high-dim
PCR X variance → Prediction Any No (PCA step) When max-var = predictive
RRR Prediction error n > p Yes Multi-output regression

Visual Summary: Decision Tree

Key Takeaways

TipSummary

  1. CCA maximizes correlation; needs n > p + q; scale-invariant

  2. PLS maximizes covariance; works with any n, p; accounts for variance

  3. PCR ignores Y when finding X components; can miss predictive patterns

  4. Use CCA when you have enough samples and want correlation focus

  5. Use PLS for high-dimensional data or when variance matters

  6. PLS is more robust to the common problems in neuroimaging data

### PCR Implementation

```{r}
#| label: pcr-demo

# PCR implementation
# Step 1: PCA on X
pca_X <- prcomp(X, center = TRUE, scale. = TRUE)

# Step 2: Regress Y on first k components
k <- 3  # Number of components
pc_scores <- pca_X$x[, 1:k]

# Regression
pcr_model <- lm(Y[, 1] ~ pc_scores)

cat("PCR Results (predicting Y1):\n")
cat("============================\n")
cat("Variance explained by first", k, "PCs:",
    round(sum(pca_X$sdev[1:k]^2) / sum(pca_X$sdev^2) * 100, 1), "%\n")
cat("R² of regression:", round(summary(pcr_model)$r.squared, 3), "\n")
```

### The PCR Problem

PCR finds directions that explain **variance in X**, not relationships with Y.

```{r}
#| label: pcr-problem
#| fig-width: 10
#| fig-height: 5

# Create extreme example
set.seed(456)
n <- 100

# X1 has high variance but no relation to Y
# X2 has low variance but strong relation to Y
X_demo <- cbind(
  X1 = rnorm(n, sd = 10),  # High variance, unrelated
  X2 = rnorm(n, sd = 1)    # Low variance
)
Y_demo <- 2 * X_demo[, 2] + rnorm(n, sd = 0.5)  # Y depends on X2!

# PCA picks X1 first
pca_demo <- prcomp(X_demo, center = TRUE, scale. = FALSE)

# PCR with 1 component (will use mostly X1)
pc1 <- pca_demo$x[, 1]
pcr_r2 <- cor(pc1, Y_demo)^2

# Compare to using X2 directly
direct_r2 <- cor(X_demo[, 2], Y_demo)^2

cat("PCA loadings (PC1):\n")
cat("  X1:", round(pca_demo$rotation[1, 1], 3), "(high variance variable)\n")
cat("  X2:", round(pca_demo$rotation[2, 1], 3), "(predictive variable)\n\n")

cat("R² predicting Y:\n")
cat("  Using PC1 (PCR):", round(pcr_r2, 3), "\n")
cat("  Using X2 directly:", round(direct_r2, 3), "\n\n")

cat("PCR misses the relationship because PCA ignores Y!\n")
```

### PCR vs PLS Comparison

```{r}
#| label: pcr-vs-pls
#| fig-width: 10
#| fig-height: 5

# Using our demonstration data
# PLS would find X2
X_c <- scale(X_demo, center = TRUE, scale = FALSE)
Y_c <- scale(Y_demo, center = TRUE, scale = FALSE)
R <- t(X_c) %*% Y_c
svd_pls <- svd(R)

pls_weights <- svd_pls$u[, 1]
pls_score <- X_c %*% pls_weights
pls_r2 <- cor(pls_score, Y_demo)^2

cat("Method comparison:\n")
cat("==================\n")
cat("PCR weight on X1:", round(pca_demo$rotation[1, 1], 3), "\n")
cat("PCR weight on X2:", round(pca_demo$rotation[2, 1], 3), "\n")
cat("PCR R² with Y:", round(pcr_r2, 3), "\n\n")

cat("PLS weight on X1:", round(pls_weights[1], 3), "\n")
cat("PLS weight on X2:", round(pls_weights[2], 3), "\n")
cat("PLS R² with Y:", round(pls_r2, 3), "\n")
```

::: {.callout-important}
## Key Insight

**PLS beats PCR** when the directions of maximum variance in X are not the most predictive of Y. PLS explicitly looks for X directions that relate to Y.
:::

## Reduced Rank Regression (RRR)

### What RRR Does

RRR finds the best low-rank approximation to the regression coefficient matrix:

$$Y = XB + E, \quad \text{where } B \text{ has rank } k$$

It's a compromise between full regression and PCA-style dimension reduction.

### Relationship to PLS

RRR can be viewed as finding the same subspace as PLS, but:

- RRR minimizes prediction error
- PLS maximizes covariance

For standardized data, they often give similar results.

## Key Takeaways

::: {.callout-tip}
## Summary

1. **CCA** maximizes correlation; needs n > p + q; scale-invariant

2. **PLS** maximizes covariance; works with any n, p; accounts for variance

3. **PCR** ignores Y when finding X components; can miss predictive patterns

4. **Use CCA** when you have enough samples and want correlation focus

5. **Use PLS** for high-dimensional data or when variance matters

6. **PLS is more robust** to the common problems in neuroimaging data
:::
