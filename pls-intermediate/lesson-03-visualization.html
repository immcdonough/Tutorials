Lesson 3: Visualization and Reporting

Creating publication-quality figures

Learning Objectives

By the end of this lesson, you will be able to:

  1. Create multi-panel summary figures for PLS results
  2. Customize colors, fonts, and themes
  3. Add panel tags (A, B, C) for publications
  4. Export figures in various formats

Setup

# Source the plscmd package (all files)
source("setup.R")
plscmd package loaded successfully!
library(ggplot2)

set.seed(42)

# Create simulated data with clear signal
n_subj <- 40
n_regions <- 40
n_behav <- 5
n_cond <- 1  # Single condition for clearer visualization

# Behavioral data
behavdata <- matrix(rnorm(n_subj * n_behav), nrow = n_subj, ncol = n_behav)
colnames(behavdata) <- c("Working_Memory", "Attention", "Processing_Speed",
                          "Verbal_Fluency", "Executive_Function")

# Brain data with injected signal
brain_data <- matrix(rnorm(n_subj * n_regions),
                      nrow = n_subj, ncol = n_regions)

# Inject strong signal in some regions
for (r in 1:8) {
  brain_data[, r] <- brain_data[, r] + 0.7 * behavdata[, 1]
}
for (r in 9:14) {
  brain_data[, r] <- brain_data[, r] - 0.5 * behavdata[, 2]
}

# Create region names (simulating brain regions)
region_names <- c(
  paste0("L_", c("DLPFC", "VLPFC", "ACC", "Insula", "Hippocampus",
                  "Amygdala", "Thalamus", "Caudate")),
  paste0("R_", c("DLPFC", "VLPFC", "ACC", "Insula", "Hippocampus",
                  "Amygdala", "Thalamus", "Caudate")),
  paste0("L_", c("V1", "V2", "MT", "FFA", "PPA", "IPS", "SPL", "IPL",
                  "STS", "TPJ", "Precuneus", "PCC")),
  paste0("R_", c("V1", "V2", "MT", "FFA", "PPA", "IPS", "SPL", "IPL",
                  "STS", "TPJ", "Precuneus", "PCC"))
)

# Run PLS
result <- pls_analysis(
  datamat_lst = list(brain_data),
  num_subj_lst = c(n_subj),
  num_cond = n_cond,
  option = list(
    method = 3,
    num_perm = 500,
    num_boot = 500,
    stacked_behavdata = behavdata,
    verbose = FALSE
  )
)

cat("Analysis complete. LV1 p-value:", result$perm_result$sprob[1], "\n")
Analysis complete. LV1 p-value: 0

The Visualization Functions

The plscmd package includes several visualization functions:

Function Purpose
plot_bootstrap_ratios() Bar plot of bootstrap ratios for brain regions
plot_lv_correlations() Bar plot of behavioral correlations
plot_brain_behavior_scatter() Scatter plot of brain vs behavior scores
plot_behavior_correlations() Correlations with bootstrap CIs
plot_lv_summary() Combined multi-panel figure
plot_all_significant_lvs() Automatic plots for all significant LVs

Advanced: Combining with Other Plots

You can combine plscmd plots with other ggplot2 figures using patchwork:

library(patchwork)

# Create individual plots
p_bsr <- plot_bootstrap_ratios(result, lv = 1,
                                region_names = region_names,
                                show_all = TRUE)

p_scatter <- plot_brain_behavior_scatter(result, lv = 1, p_digits = 3)

# Combine side by side
combined <- p_bsr + p_scatter +
  plot_annotation(
    title = "LV1: Brain-Behavior Relationship",
    tag_levels = "A",
    theme = theme(plot.title = element_text(face = "bold", size = 16, hjust = 0.5))
  )

print(combined)

Tips for Publication-Quality Figures

TipBest Practices
  1. Resolution: Use at least 300 DPI for print, 150 DPI for web
  2. Dimensions: Match journal requirements (often 3.5” or 7” wide)
  3. Fonts: Use consistent font sizes; 8-10pt is typical for axis labels
  4. Colors: Ensure colorblind accessibility; test with grayscale
  5. Tags: Use consistent panel labeling (A, B, C or a, b, c)
  6. File format: PDF for vector graphics, TIFF/PNG for raster
