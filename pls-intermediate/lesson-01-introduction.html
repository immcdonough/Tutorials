Setup

First, let’s load the package and set a seed for reproducibility:

# Source the plscmd package (all files)
source("setup.R")

What is PLS?

Partial Least Squares (PLS) is a multivariate statistical technique that finds linear combinations of variables from two data matrices that have maximum covariance with each other.

When to Use PLS

PLS is ideal when you have:

  • Two sets of variables you want to relate (e.g., brain measures and behaviors)
  • More variables than observations (common in neuroimaging)
  • Multicollinearity in your predictors
  • A desire to find patterns rather than predict specific outcomes

PLS vs. Other Methods

Method Use Case
PLS Find patterns relating two variable sets
PCA Reduce dimensionality of one variable set
CCA Find correlations between two sets (requires n > p)
Regression Predict one outcome from predictors

Data Structure

The plscmd package expects data in a specific format:

Brain Data (datamat_lst)

A list of matrices, where each matrix represents a group:

  • Rows = subjects
  • Columns = brain variables (voxels, ROIs, connections)
# Simulate brain data: 2 groups, 15 subjects each, 50 brain regions
n_subj_per_group <- 15
n_regions <- 50
n_groups <- 2
n_conditions <- 3  # e.g., rest, task1, task2

# Create data for each group
# Each group's data is stacked: (n_subjects * n_conditions) x n_regions
group1_data <- matrix(rnorm(n_subj_per_group * n_conditions * n_regions),
                       nrow = n_subj_per_group * n_conditions,
                       ncol = n_regions)
group2_data <- matrix(rnorm(n_subj_per_group * n_conditions * n_regions),
                       nrow = n_subj_per_group * n_conditions,
                       ncol = n_regions)

# Put into a list
datamat_lst <- list(group1_data, group2_data)

# Check dimensions
cat("Group 1 dimensions:", dim(datamat_lst[[1]]), "\n")
Group 1 dimensions: 45 50 
cat("Group 2 dimensions:", dim(datamat_lst[[2]]), "\n")
Group 2 dimensions: 45 50
ImportantData Stacking Convention

Within each group matrix, data is stacked by condition within subject:

  • Rows 1 to n_conditions: Subject 1’s data across conditions
  • Rows (n_conditions + 1) to (2 * n_conditions): Subject 2’s data
  • And so on…

Behavioral Data (behavdata or stacked_behavdata)

A matrix of behavioral measures:

  • Rows = subjects (matching the brain data)
  • Columns = behavioral variables
# Simulate behavioral data: 3 measures per subject
n_behav <- 3
total_subjects <- n_subj_per_group * n_groups

# Create behavioral matrix (one row per subject, replicated across conditions)
behavdata_base <- matrix(rnorm(total_subjects * n_behav),
                          nrow = total_subjects,
                          ncol = n_behav)
colnames(behavdata_base) <- c("Memory", "Attention", "Processing_Speed")

# Stack to match brain data structure (repeat for each condition)
stacked_behavdata <- do.call(rbind, lapply(1:n_conditions, function(c) behavdata_base))

cat("Behavioral data dimensions:", dim(stacked_behavdata), "\n")

Your First PLS Analysis

Now let’s run a complete PLS analysis:

# Define the analysis parameters
num_subj_lst <- c(n_subj_per_group, n_subj_per_group)  # subjects per group
num_cond <- n_conditions  # number of conditions

# Set up options
option <- list(
  method = 3,           # Behavior PLS (correlating brain with behavior)
  num_perm = 500,       # Permutation tests (use 1000+ for publication)
  num_boot = 500,       # Bootstrap samples (use 1000+ for publication)
  stacked_behavdata = stacked_behavdata,
  verbose = FALSE       # Suppress progress messages
)

# Run the analysis
result <- pls_analysis(
  datamat_lst = datamat_lst,
  num_subj_lst = num_subj_lst,
  num_cond = num_cond,
  option = option
)

cat("Analysis complete!\n")
Analysis complete!
cat("Number of latent variables:", length(result$s), "\n")
Number of latent variables: 18

## What is PLS?

**Partial Least Squares (PLS)** is a multivariate statistical technique that finds linear combinations of variables from two data matrices that have maximum covariance with each other.

### When to Use PLS

PLS is ideal when you have:

- **Two sets of variables** you want to relate (e.g., brain measures and behaviors)
- **More variables than observations** (common in neuroimaging)
- **Multicollinearity** in your predictors
- A desire to find **patterns** rather than predict specific outcomes

### PLS vs. Other Methods

| Method | Use Case |
|--------|----------|
| **PLS** | Find patterns relating two variable sets |
| **PCA** | Reduce dimensionality of one variable set |
| **CCA** | Find correlations between two sets (requires n > p) |
| **Regression** | Predict one outcome from predictors |

## Your First PLS Analysis

Now let's run a complete PLS analysis:

```{r}
#| label: first-analysis

# Define the analysis parameters
num_subj_lst <- c(n_subj_per_group, n_subj_per_group)  # subjects per group
num_cond <- n_conditions  # number of conditions

# Set up options
option <- list(
  method = 3,           # Behavior PLS (correlating brain with behavior)
  num_perm = 500,       # Permutation tests (use 1000+ for publication)
  num_boot = 500,       # Bootstrap samples (use 1000+ for publication)
  stacked_behavdata = stacked_behavdata,

# Run the analysis
result <- pls_analysis(
  datamat_lst = datamat_lst,
```

## Understanding the Results Object

The `pls_analysis` function returns a list with many components:

```{r}
#| label: result-structure

# See what's in the result
names(result)
```

### Key Components

| Component | Description |
|-----------|-------------|
| `s` | Singular values (strength of each LV) |
| `u` | Brain saliences (weights for brain variables) |
| `v` | Behavior saliences (weights for behavior variables) |
| `usc` | Brain scores (subjects' expression of brain pattern) |
| `vsc` | Behavior scores (subjects' expression of behavior pattern) |
| `perm_result` | Permutation test results |
| `boot_result` | Bootstrap results |

### Singular Values

The singular values indicate how much covariance each LV captures:

```{r}
#| label: singular-values

# Singular values
result$s

# Variance explained by each LV

  cat(sprintf("  LV%d: %.1f%%\n", i, var_explained[i]))
}
```

### Saliences

Saliences are the weights that define each latent variable:

```{r}
#| label: saliences
```

### Scores

Scores represent how strongly each subject expresses the pattern:

```{r}

cat("Brain scores dimensions:", dim(result$usc), "\n")

# Behavior scores

# The correlation between brain and behavior scores

cat("\nCorrelation of brain-behavior scores vs singular value:\n")
for (lv in 1:min(3, length(result$s))) {
  r <- cor(result$usc[, lv], result$vsc[, lv])
  cat(sprintf("  LV%d: r = %.3f, s = %.3f\n", lv, r, result$s[lv]))
}
```
