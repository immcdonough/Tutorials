Lesson 2: Understanding PLS Results

Permutation testing, bootstrap ratios, and interpretation

Learning Objectives

By the end of this lesson, you will be able to:

  1. Interpret permutation test results to determine significant LVs
  2. Use bootstrap ratios to identify reliable brain regions
  3. Understand confidence intervals for behavioral correlations
  4. Make informed decisions about which results to report

Setup

# Source the plscmd package (all files)
source("setup.R")
plscmd package loaded successfully!
set.seed(42)

# Create simulated data with a known signal
n_subj <- 30
n_regions <- 50
n_behav <- 4
n_cond <- 1  # Single condition for clearer demonstration
n_groups <- 1

# Create behavioral data
behavdata <- matrix(rnorm(n_subj * n_behav), nrow = n_subj, ncol = n_behav)
colnames(behavdata) <- c("Memory", "Attention", "Speed", "Accuracy")

# Create brain data with some regions correlated with behavior
brain_data <- matrix(rnorm(n_subj * n_regions),
                      nrow = n_subj, ncol = n_regions)

# Inject signal: regions 1-10 correlate with Memory (behavior 1)
for (r in 1:10) {
  brain_data[, r] <- brain_data[, r] + 0.5 * behavdata[, 1]
}

# Regions 11-15 correlate with Attention (behavior 2)
for (r in 11:15) {
  brain_data[, r] <- brain_data[, r] + 0.4 * behavdata[, 2]
}

# Run PLS analysis
result <- pls_analysis(
  datamat_lst = list(brain_data),
  num_subj_lst = c(n_subj),
  num_cond = n_cond,
  option = list(
    method = 3,
    num_perm = 1000,
    num_boot = 1000,
    stacked_behavdata = behavdata,
    verbose = FALSE
  )
)

Permutation Testing

Why Permutation Tests?

PLS always finds latent variables - even with random data. We need to test whether the observed patterns are statistically significant or could have occurred by chance.

Permutation testing:

  1. Shuffles the correspondence between brain and behavior data
  2. Runs PLS on the shuffled data
  3. Repeats many times to build a null distribution
  4. Compares observed singular values to null distribution

Bootstrap Ratios

What Are Bootstrap Ratios?

While permutation tests tell us if an LV is significant, bootstrap ratios tell us which specific variables contribute reliably to that LV.

Bootstrap ratio = salience / standard error

This is analogous to a z-score:

  • |BSR| > 1.96 ≈ p < 0.05
  • |BSR| > 2.58 ≈ p < 0.01
  • |BSR| > 3.29 ≈ p < 0.001

Examining Bootstrap Ratios

boot <- result$boot_result

# Bootstrap ratios for brain saliences (LV1)
bsr_brain <- boot$compare_u[, 1]

# Standard errors
se_brain <- boot$u_se[, 1]

# Create a summary
bsr_summary <- data.frame(
  Region = 1:n_regions,
  Salience = result$u[, 1],
  SE = se_brain,
  BSR = bsr_brain,
  Significant = abs(bsr_brain) > 1.96
)

# Show regions with highest absolute BSR
top_regions <- bsr_summary[order(abs(bsr_summary$BSR), decreasing = TRUE), ]
head(top_regions, 10)

ImportantConservative Significance

The plscmd package uses a conservative criterion: a region is considered significant only if the lower bound of its confidence interval (|BSR| - SE) exceeds the threshold. This is more stringent than simply checking if |BSR| > threshold.

Interpreting Results

A Complete Interpretation Workflow

# Step 1: Which LVs are significant?
cat("Step 1: Significant Latent Variables\n")
Step 1: Significant Latent Variables
cat("=====================================\n")
=====================================
sig_lvs <- which(perm$sprob < 0.05)
if (length(sig_lvs) > 0) {
  cat("Significant LVs:", paste(sig_lvs, collapse = ", "), "\n\n")
} else {
  cat("No significant LVs found.\n\n")
}
Significant LVs: 1 
# Step 2: For each significant LV, examine the pattern
for (lv in sig_lvs) {
  cat(sprintf("\nLV%d Analysis (p = %.4f)\n", lv, perm$sprob[lv]))
  cat(paste(rep("-", 40), collapse = ""), "\n")

  # Variance explained
  var_exp <- (result$s[lv]^2) / sum(result$s^2) * 100
  cat(sprintf("Variance explained: %.1f%%\n\n", var_exp))

  # Significant behaviors
  orig_corr <- boot$orig_corr[, lv]
  ll <- boot$llcorr[, lv]
  ul <- boot$ulcorr[, lv]
  sig_behav <- sign(ll) == sign(ul)

  cat("Significant behavioral correlations:\n")
  for (b in which(sig_behav)) {
    cat(sprintf("  %s: r = %.2f [%.2f, %.2f]\n",
                colnames(behavdata)[b], orig_corr[b], ll[b], ul[b]))
  }

  # Count significant brain regions
  bsr <- boot$compare_u[, lv]
  se <- boot$u_se[, lv]
  sig_pos <- sum((bsr - se) > 1.96)
  sig_neg <- sum((bsr + se) < -1.96)

  cat(sprintf("\nSignificant brain regions:\n"))
  cat(sprintf("  Positive: %d regions\n", sig_pos))
  cat(sprintf("  Negative: %d regions\n", sig_neg))
}

Effect Size and Practical Significance

Beyond Statistical Significance

Even significant results may not be practically meaningful. Consider:

  1. Variance Explained: How much of the total covariance does this LV capture?
  2. Effect Size: How strong are the correlations?
  3. Number of Significant Variables: A pattern supported by many variables is more robust.

Exercise 2: Threshold Sensitivity

Explore how the number of significant regions changes with different thresholds:

# Try different thresholds
thresholds <- c(1.64, 1.96, 2.58, 3.29)
threshold_names <- c("p<0.10", "p<0.05", "p<0.01", "p<0.001")

for (i in seq_along(thresholds)) {
  bsr <- result$boot_result$compare_u[, 1]
  se <- result$boot_result$u_se[, 1]
  n_sig <- sum(abs(bsr) - se > thresholds[i])
  cat(sprintf("%s (|BSR|>%.2f): %d regions\n",
              threshold_names[i], thresholds[i], n_sig))
}

Common Pitfalls

WarningAvoid These Mistakes

  1. Ignoring non-significant LVs’ patterns: Even if LV1 is not significant, don’t interpret the brain-behavior pattern.

  2. Over-interpreting single regions: A pattern is defined by the whole brain, not individual regions.

  3. Forgetting about multiple comparisons: Consider FDR correction if testing many regions.

  4. Confusing correlation with causation: PLS finds associations, not causal relationships.

Summary

In this lesson, you learned:

  • Permutation testing determines if LVs capture real signal or noise
  • Bootstrap ratios identify which variables reliably contribute to each LV
  • Confidence intervals for behavioral correlations show reliability
  • Both statistical and practical significance should be considered

## Interpreting Results

### A Complete Interpretation Workflow

```{r}
#| label: interpretation

cat("Step 1: Significant Latent Variables\n")

if (length(sig_lvs) > 0) {
  cat("Significant LVs:", paste(sig_lvs, collapse = ", "), "\n\n")

# Step 2: For each significant LV, examine the pattern
for (lv in sig_lvs) {

  # Variance explained

  orig_corr <- boot$orig_corr[, lv]
  ll <- boot$llcorr[, lv]
  ul <- boot$ulcorr[, lv]

  cat("Significant behavioral correlations:\n")
  for (b in which(sig_behav)) {
    cat(sprintf("  %s: r = %.2f [%.2f, %.2f]\n",
                colnames(behavdata)[b], orig_corr[b], ll[b], ul[b]))
  }

  # Count significant brain regions
  bsr <- boot$compare_u[, lv]
  se <- boot$u_se[, lv]
  sig_pos <- sum((bsr - se) > 1.96)
  sig_neg <- sum((bsr + se) < -1.96)

  cat(sprintf("\nSignificant brain regions:\n"))
  cat(sprintf("  Positive: %d regions\n", sig_pos))
  cat(sprintf("  Negative: %d regions\n", sig_neg))
}
```
