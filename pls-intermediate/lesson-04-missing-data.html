The Missing Data Problem

Missing data is common in research:

  • Participants drop out
  • Equipment fails
  • Data quality checks exclude values
  • Questionnaires have unanswered items

Types of Missing Data

Type Description Implication
MCAR Missing Completely At Random Safe to impute or delete
MAR Missing At Random (conditional on observed data) Imputation is valid
MNAR Missing Not At Random Imputation may be biased
ImportantWhy Not Just Delete?

Complete case deletion (listwise deletion):

  • Reduces sample size and power
  • May introduce bias if data is not MCAR
  • Wastes information from partially complete cases

Creating Data with Missing Values

Let’s create a realistic dataset with missing values:

# Create complete data first
n_subj <- 40
n_regions <- 30
n_behav <- 4
n_cond <- 2

Single Imputation

Mean Imputation

The simplest approach - replace missing values with the column mean:

# Impute with mean
imputed_mean <- pls_impute(
  datamat_lst = list(brain_missing),
  behavdata = stacked_behav_missing,
  method = "mean",
  m = 1,
  verbose = TRUE
)

# Verify no missing values

WarningLimitations of Mean Imputation

Mean imputation:

  • Underestimates variance
  • Distorts correlations
  • Biases standard errors downward

Use only for very low missingness (< 5%) or as a quick check.

Random Forest Imputation

A more sophisticated approach using predictive models:

# Random forest imputation (requires missRanger package)
imputed_rf <- pls_impute(
  datamat_lst = list(brain_missing),
  behavdata = stacked_behav_missing,
  method = "rf",
  m = 1,
  maxiter = 10,
  verbose = TRUE
)

The pls_analysis() function can handle imputation automatically:

# Run PLS with automatic mean imputation
result_imputed <- pls_analysis(

  num_cond = n_cond,
  option = list(
    method = 3,
    num_perm = 500,
    num_boot = 500,
    stacked_behavdata = stacked_behav_missing,
    impute_method = "mean",  # Automatic imputation

NoteDefault Behavior

By default, pls_analysis() will error if missing data is present and no impute_method is specified. This is intentional - it forces you to make a conscious decision about how to handle missing data.

Multiple Imputation

Why Multiple Imputation?

Single imputation treats imputed values as if they were known. Multiple imputation accounts for uncertainty:

  1. Create multiple (m) complete datasets with different imputed values
  2. Analyze each dataset separately
  3. Pool results using Rubin’s rules

Creating Multiple Imputations

# Create 5 imputed datasets

Rubin’s Rules for Pooling

Theory

When pooling results from multiple imputations:

Point estimate (pooled coefficient): \[\bar{\theta} = \frac{1}{m} \sum_{i=1}^{m} \hat{\theta}_i\]

Within-imputation variance: \[\bar{W} = \frac{1}{m} \sum_{i=1}^{m} W_i\]

Between-imputation variance: \[B = \frac{1}{m-1} \sum_{i=1}^{m} (\hat{\theta}_i - \bar{\theta})^2\]

Total variance: \[T = \bar{W} + \left(1 + \frac{1}{m}\right) B\]

Using pool_estimates()

Best Practices

TipRecommendations
  1. Always report the amount and pattern of missing data
  2. Use multiple imputation when missingness > 5%
  3. Use at least 5 imputations (more for higher missingness)
  4. Random forest imputation generally outperforms mean imputation
  5. Check sensitivity by comparing results across methods
  6. Document your approach for reproducibility

## Rubin's Rules for Pooling

### Theory

When pooling results from multiple imputations:

**Point estimate** (pooled coefficient):
$$\bar{\theta} = \frac{1}{m} \sum_{i=1}^{m} \hat{\theta}_i$$

**Within-imputation variance**:
$$\bar{W} = \frac{1}{m} \sum_{i=1}^{m} W_i$$

**Between-imputation variance**:
$$B = \frac{1}{m-1} \sum_{i=1}^{m} (\hat{\theta}_i - \bar{\theta})^2$$

**Total variance**:
$$T = \bar{W} + \left(1 + \frac{1}{m}\right) B$$

### Using pool_estimates()

```{r}
#| label: pool-demo

# Simulate results from 5 imputations
set.seed(123)
m <- 5

# Simulated singular values from each imputation

  c(2.1, 2.3, 2.0, 2.2, 2.15,  # LV1
    1.5, 1.4, 1.6, 1.45, 1.55, # LV2
    0.8, 0.9, 0.85, 0.82, 0.88), # LV3
  nrow = m, ncol = 3, byrow = FALSE
)

# Simulated variances (squared SEs)
variances <- matrix(0.01, nrow = m, ncol = 3)

# Pool the estimates
pooled <- pool_estimates(estimates, variances)

cat("Pooled estimates:\n")
print(round(pooled$pooled, 3))

cat("\nTotal variance:\n")
print(round(pooled$total_var, 4))

cat("\nFraction of Missing Information (FMI):\n")
print(round(pooled$fmi, 3))
```

## Best Practices

::: {.callout-tip}
## Recommendations

1. **Always report** the amount and pattern of missing data
2. **Use multiple imputation** when missingness > 5%
3. **Use at least 5 imputations** (more for higher missingness)
4. **Random forest** imputation generally outperforms mean imputation
5. **Check sensitivity** by comparing results across methods
6. **Document your approach** for reproducibility
:::
