## Welcome

This is a 5-lesson course on **cross-validated neural pattern analysis** for measuring how distinctly the brain represents different categories (e.g., faces vs. objects) during cognitive tasks.

## Course Overview

| Lesson | Topic | Duration |
|--------|-------|----------|
| 1 | Core Concepts: Mahalanobis, RDMs, RSA | ~45 min |
| 2 | GLM & HRF Convolution | ~60 min |
| 3 | Pattern Extraction & Parcellation | ~45 min |
| 4 | Cross-Validation & Distance Computation | ~60 min |
| 5 | Group Statistics & Validation | ~45 min |

## Prerequisites

- Basic Python programming
- Familiarity with fMRI data concepts
- Linear algebra fundamentals

## Key Concepts You'll Learn

1. **Mahalanobis Distance** - Multivariate distance normalized by noise covariance
2. **Cross-Validation** - Leave-one-run-out for unbiased estimates
3. **RSA** - Representational Similarity Analysis
4. **FDR Correction** - Multiple comparison correction for 360 parcels
5. **The N-back Confound** - Why we use 4-condition instead of 6-condition models
